# 算法指导

本文件说明代码里**真正实现了什么**，以及公式与文件的对应关系。所有陈述均可按给出的
`文件:行号` 复核。

---

## 一、一句话概括

> 给定**目标参考模型**（要检查什么）与**已有点云**，找出哪些目标表面没测够，
> 再在移动平台走得到的地方选出补扫站位，使被补上的目标缺口最多。

方法**不是**无模型 SLAM 探索：目标表面的参考几何是必需的先验；现场环境几何则不要求
预先完整给出。

## 三、两个模型（第二件专利的核心概念）

```
M_ref   目标参考模型 —— 回答"我要检查什么"
        目标构件清单、目标表面几何、工程属性（重要度、密度要求、是否带电）
        作业前给定，全程不变

M_plan  规划环境模型 —— 回答"现在认为哪里能走、什么会挡住视线"
        = { M_occ , M_vis }
```

| 子部分 | 内容 | 初始内容来自 | 代码 |
|---|---|---|---|
| **M_occ** 占据/通行侧 | 三态平面栅格 ＋ 安全禁入 | **初始扫描的实测点云** | `SimWorld.env`（`PlanningEnvGrid`） |
| **M_vis** 遮挡/可见性侧 | 射线求交用的三角网 | **至少含 M_ref 目标表面** ＋ 地面 ＋ 该场景可获得的已知环境几何 | `SimWorld.plan_oracle`（内容由 `SimWorld.ref_tris` 决定） |

> **不得**表述为「M_plan 完全由点云建立」—— 对 M_vis 不成立。

### 三态栅格（`mapping/planning_env.py`）

| 状态 | 含义 | 处置 |
|---|---|---|
| `OCCUPIED` | 通行高度带 `[0.20, 1.80] m` 内有回波 | 障碍 |
| `FREE` | 站位到回波点的连线（按 XY 投影）经过此处 | 可通行 |
| `UNKNOWN` | 无证据 | **不作为可通行区域**（`unknown_is_free` 缺省 False） |

三条须知：

1. **占据优先**：已确认占据的格不被后续射线抹回自由。
2. **平台站过的格不被膨胀抹掉**（`_stood`），但**已确认占据的格除外**。不加这一条会
   出现"平台被卡在自己正站着的位置上"，其后距离场处处为无穷。
3. **FREE carving 是二维投影近似**，不考虑射线高度随距离变化。实测"说能走实际不能走"
   占 1.41%，反方向（保守判为不可走）占 14.31%，整体偏保守。**不得**写成"证明该处
   可通行"。

## 四、关键公式与其真实实现

### 4.1 缺口分数

`gap/scoring.py:205-212`（几何证据 D_geo）：

```
D_geo = 0.60 · (1 − C_i) + 0.40 · (1 − clip(ρ_i/ρ̂_i, 0, 1))
```

真正的 `G_gap` 是六项证据（D_sem、D_mat_missing、D_mat_conflict、D_obs、D_ang、
D_geo）的归一化加权和（`scoring.py:242`）；`G_task = G_gap·(1+λ·E_i)`（`:249`）。

### 4.2 点云密度与期望密度

```python
# density/expected.py:52
rho_obs = n_points / max(area, 1e-9)              # 面密度, 单位 点/m²
# density/expected.py:39-42
rho_req = rho0 * (1 + lambda_e * clip(E_i, 0, 1)) # 按工程重要度分级
```

**代码中没有任何体密度（球体体积倒数）实现。**

### 4.3 几何覆盖率

两条路径不同，引用时必须说清是哪条：

- **仿真路径** `closed_loop_v2.py:208-218`：`C_i` = 该分块采样点中被任一已执行站
  观测到的比例（射线可见性统计）。
- **真实点云路径** `evidence/__init__.py:407-409`：`coverage_ratio = clip(density_ratio, 0, 1)`
  —— 是密度比的**代理**。此时 C_i 与 ρ_i 不再独立，D_geo 的两项会退化为一项。

### 4.4 视点价值（母专利式，`viewpoints/ranking.py:242-258`）

```python
q       = frontality × dist_quality × res_quality        # 逐(视点,分块)对 → q_{jk}
value   = Σ_k  G_k · q_{jk} · A_k
最终值   = value − eta · overlap                          # eta = 0.10
overlap = 0.1 · 非目标分块数 / 可见分块数                  # 冗余惩罚, 非"覆盖比例"
```

三个质量因子：

| 因子 | 式子 | 缺省参数 |
|---|---|---|
| 正视度 | `dot(n_k, 分块→视点方向).clip(0,1)` | 下限 0.35 |
| 距离质量 | `exp(−(d−r_opt)²/(2σ²))` | `r_opt = 2.5 m`；`σ = 2.0`（显式给 `r_opt_m` 时才取 `0.4·r_opt`） |
| 分辨率质量 | `clip(1/(1+0.15·d), 0, 1)` | — |

可见性为**二值**判定：正视度 ≥ 下限、朝向夹角余弦 ≥ cos(视场半角)、距离 ≤ 最大量程
（缺省视场 90°、量程 20 m）。**代码中没有"部分覆盖面积比例"的计算。**

### 4.5 表面分块构造（`patches/__init__.py:56-81`）

```python
for start in range(n):                    # 逐个未归属三角面作种子, 循环
    ...
    if (dot(local_normals[cur], nb) >= cos_threshold        # 第一约束: 与已纳入的相邻面
            and dot(seed_normal, nb) >= cos_threshold):     # 第二约束: 与种子面
```

- 邻接由**共享无向边**建立（`:41-53`），**只在同一构件内部**；
- **两条约束共用同一阈值** `cos_threshold`（由 `normal_threshold_deg = 20°` 得到）；
- 代码**不计算连通分量**，没有"生长区域"这一独立步骤；
- 面积小于 `min_patch_area`（缺省 0.005 m²）的分块被**丢弃**；
- 分块中心与法向均为按**三角面面积加权**的平均（`:195-199`）。

### 4.6 点—分块关联与等距裁决

- 关联阈值 `association_distance = 0.05 m`（`data/pointcloud.py`）；
- 等距时按 `data/tie_break.py` 的**四级确定性规则**裁决：距离最小（含 1e-6 m 容差）→
  最近表面点方向与法向夹角余弦绝对值最大 → 顶点坐标字典序最小 → 按构件标识；
  第三级用几何量而非存储索引，故结果**不依赖三角面的存储顺序**；
- **真实数据路径的关联输出是构件级**（`element_index`/`element_guid`），分块级点数由
  `est_count = full_count × area_ratio` **按面积比例摊派估算**（`evidence/__init__.py:383-386`）。

### 4.7 在线环境发现 S7a（`occlusion/discovery.py`）

```python
d   = 到"规划环境模型遮挡侧初始内容"的距离     # 基准 = world.ref_tris
far = pts[d > EPS_UNMODELED]                  # 0.25 m
体素化(0.40 m) → 累积到集合 → 并入 M_vis
```

- 基准是**该先验档实际提供的几何**，不是"仅目标表面"；
- 已作为环境先验给出的构件**不会被重复发现**（表面点距离≈噪声 ≪ 0.25 m）；
- 发现的体素 `tri_to_patch = −1`：**只作遮挡体，不成为新的待扫目标**；
- 累积是集合，**幂等**（同一批点二次并入新增 0）。

## 五、方法代号

| 代号 | 含义 |
|---|---|
| `B0_random` | 自由格随机 |
| `Bdisp_maxmin` | 无信息最大离散（不用任何缺口证据） |
| `Bbim_offline` | 纯 BIM 离线覆盖规划（首轮定死，不重规划） |
| `B1_patent` | **母专利原式**（`viewpoints/ranking.py`） |
| `B5_occ_rng` | 仅遮挡 ＋ 量程 |
| `B10_full` | 完整价值函数（公式 26–45），**不开**在线环境更新 |
| `B11_disc` | B10 ＋ **在线环境更新** |
| `Bfrontier` | frontier 探索基线（收益 = 新揭示未知栅格数） |

`B10` 与 `B11` 只差一个开关，故 `B11 − B10` 可干净归因于在线环境更新。
`Bfrontier` 与 B10/B11 的候选空间、收益口径、有无遮挡模型三者同时不同，**差值不可
归因于其中任一单项**。

## 七、三条必须随算法一起交代的边界

1. **初始站位是作业输入**，不由本方法规划。本方法不解决"完全无信息时如何架第一站"。
2. **本方法针对的是"已有初始扫描之后的补扫"**：实测 P0 条件下仅初始三站后，M_occ
   已确认约 89% 的二维栅格。不用于证明从完全未知环境开始的自主探索。
3. **FREE carving 是二维投影近似**（见第三节）。
