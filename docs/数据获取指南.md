# 数据获取指南

**核心结论：主要实验（E2 / E3b / E5 / E7 / E8，共 696 次运行）不需要下载任何外部
数据** —— 场景由代码按种子生成，完全可复现。只有真实建筑实施例 E6 需要外部数据集。

---

## 一、合成场景：零下载，由代码生成

### 1.1 生成代码

`src/patent_gap/simulation/scene_gen.py::generate_scene()`

```python
from patent_gap.simulation.scene_gen import generate_scene

scene = generate_scene(
    seed=0,           # 随机种子：同一种子必然生成同一场景
    family="S",       # 场地规模：S(44×32m) / M(58×42m) / L(74×52m)
    density="low",    # 设备密度：low(1.0) / mid(1.5) / high(2.0)
    n_temp=6,         # 竣工态临时占位物数量（设计模型中不存在的施工车辆、料堆等）
)
```

### 1.2 生成的内容

一个合成变电站场景，含：

| 类别 | 是否为待扫目标 | 说明 |
|---|---|---|
| 断路器、隔离开关、CT/PT、避雷器、变压器、母线、绝缘子、构架 | **是** | 验收要检查的资产 |
| 厂房、围墙、杂物 | 否 | 遮挡视线、影响通行，但不检查 |
| 地面 | 否 | 通行面 |
| `temp_obstacle` 临时占位物 | 否（`in_bim=False`） | **设计模型中不存在**，但会挡住扫描仪 |

规模参考：S/low 约 57 个构件、484 个目标分块；M/mid 约 80 个构件、846 个分块。

### 1.3 为什么可复现

场景生成、传感器仿真、方法内部随机全部由 `seed` 控制。同一 `(seed, family,
density, n_temp)` 必然给出同一场景与同一结果。实测：在同一 commit 上重跑三格，与盘上
结果**逐位一致**。

### 1.4 单独看一个场景

```bash
python -c "
from patent_gap.simulation.scene_gen import generate_scene
sc = generate_scene(seed=0, family='M', density='mid', n_temp=6)
print('构件数', len(sc.components), '三角面', len(sc.triangles))
import collections; print(collections.Counter(c.cls for c in sc.components))
"
```

## 二、真实建筑数据（仅 E6 需要）：CRAS

### 2.1 需要的文件

| 文件 | 体积 | 用途 |
|---|---|---|
| `craslabannotated.zip` | 4.0 GB | 标注点云 |
| `craslabbim.ifc` | 65 MB | 建筑 IFC 模型 |

**未随本迁移包分发**：体积超出合理范围，且第三方数据的再分发授权不在本项目掌握之内。

### 2.2 下载与预处理

```bash
# 1) 下载到 data/raw/
bash scripts/download_cras.sh

# 2) 检查数据完整性
python -m patent_gap.cli inspect-data --config configs/data/cras.yaml

# 3) 生成派生缓存到 data/processed/（约 41 MB）
python scripts/preprocess_cras.py

# 4) 点云—构件关联（含四级确定性等距裁决）
python scripts/run_cras_full_association.py
```

`.gitignore` 已排除 `data/raw/*.zip`、`data/raw/*.ifc`、`data/processed/`，
下载后不会被误提交。

### 2.3 CRAS 数据的一条限制

该建筑 IFC 中 **256 个构件全部为目标类，不存在非目标环境构件**。因此
**遮挡先验强度这一实验轴（P75/P50/P0）在真实数据上无法复现** —— 真实数据只支持
"通行侧"的结论。
