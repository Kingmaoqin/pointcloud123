## 三、三件读之前必须知道的事

### 1. 本包所有数字出自同一个代码版本

git commit **`5116dae`**。E7 240 次 ＋ E8 144 次运行，全部成功，每个 `run.json` 里
记录的 `git_commit` 是**单一值**；另抽 3 格在该 commit 上重跑，与盘上结果**逐位一致**。
E7/E8 正式结果产自 `5116dae`，**该版本当时 125 项测试全部通过**；完成最终 S7a 与
FREE-carving 核查后新增 3 项回归测试，**当前最终交付测试集共 128 项，全部通过**。

### 2. `实验记录/缺陷记录_勿引用/` 里的数据不得引用

那是本轮查出的一个缺陷（"平台被卡在自己正站着的位置上"）修复**之前**的运行。它压低了
全部弱先验档的数字。保留它，是为了记录"这个缺陷造成了什么"，**不是**性能数据。
详见 `03_代码修改与测试记录.md` 第 4.4 节。

### 3. 本包的数字不能与更早的 E2 / E5 / E6 直接比较

本轮统一了目标集口径：厂房、围墙、杂物不再算作待扫目标（占分块数 5.7–8.0%）。因此
**绝对数值**不可跨实验对比；**各实验内部的对照不受影响**。更早的结果全部原样保留在
盘上，未作任何修改。

## 五、最容易误读的三处（详见 00B 第十节）

| 不要读成 | 实际是 |
|---|---|
| 「不需要建模了，全靠后测」 | **目标参考模型仍是必需的**。不需要的只是"额外的非目标环境几何"。且规划环境模型的**遮挡侧**初始内容本就含目标表面与地面，不能说成"完全由点云建立" |
| 「地图覆盖得快 = 任务补得好」 | 这是两个不同的目标函数。frontier 在地图覆盖上**赢**，在资产恢复上差 0.40 |
| 「可见性误差改善 = 恢复率改善」 | 分开检验的两件事。误差改善在五档全显著；恢复率增益只在 P0 档显著 |
