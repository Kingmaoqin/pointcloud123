# 阶段 4：权利要求逻辑骨架

## 4.1 逐步骤四要素表

### S1 缺口证据与分数构建

- **输入对象**：设计建筑信息模型的三角面集合 T 及其构件划分；已采集点云 P₀。
- **执行动作**：按法向一致性将 T 切分为表面分块；将 P₀ 中的点关联至表面分块；
  逐分块统计观测量并归一为缺口证据；融合为缺口分数，再结合构件的工程重要度得到
  任务分数。
- **判断/计算依据**：沿用在先方案的分块切分与证据融合规则。
- **输出**：表面分块集合 L，每个分块携带形心、单位法向、面积、缺口分数 G_gap、
  任务分数 G_task。
- **被哪一步使用**：S3 筛目标；S4 算收益。

### S2 移动平台可通行空间构建

- **输入对象**：设计模型构件的平面占位、底面离地净空、带电构件的对地安全距离；
  移动平台的半径与高度。
- **执行动作**：建立平面栅格；按顶面高度与底面净空判定是否标记为障碍；对带电
  构件按对地安全距离追加标记；对已标记栅格按平台半径作膨胀。
- **判断/计算依据**：顶面高度是否不大于预设跨越高度（是则视为可站立地面）；
  底面净空是否大于平台高度（是则视为可从下穿行）。
- **输出**：自由空间 F。
- **被哪一步使用**：S3 投影候选、算可通行路径代价。

### S3 目标分块筛选与候选站位生成

- **输入对象**：S1 的 L；S2 的 F；当前位姿 v₀；此前各轮已执行的站位（首轮为空）。
- **执行动作**：
  (a) 目标筛选——按所属构件分组，每构件按任务分数与面积之积取不超过预设条数的
      分块，构成目标分块集合；
  (b) 候选生成——在目标分块法向侧按预设距离档取点，叠加 F 上按预设间距取的栅格
      节点；
  (c) 投影与剔除——投影至 F 内最近自由栅格，投影失败者剔除；
  (d) **可通行路径代价**——自 v₀ 在 F 上作一次单源最短路求解，得到 v₀ 至 F 内
      全部自由栅格的可通行路径代价；据此为每个候选赋路径代价 ℓ(v)；ℓ(v) 为无穷者
      剔除。
- **判断/计算依据**：每构件条数上限；集合容量随构件数缩放；可达性。
- **输出**：候选补充扫描站位集合 V，每个候选携带位置与可通行路径代价 ℓ(v)。
- **被哪一步使用**：S4 评估；S5 构成等效成本；S6 判定预算内可达。

> **注**：去重动作（剔除与已执行站位距离不大于预设去重阈值的候选）**不写入
> 权 1 的 S3**，而由从属权以自包含方式引入。见 5.A 权 9。

### S4 基于规划用遮挡模型的候选站位评估

- **输入对象**：S3 的 V；S1 的 L；**规划用遮挡模型 M_plan**（首轮为 T，其后为
  S8 更新后的版本）。
- **执行动作**：自候选向分块的表面采样点投射射线，在 M_plan 上取首次命中，得
  可见率；结合正视性与量程—点密度质量项得覆盖成功概率 q′；由 q′ 与任务分数、
  面积合成候选价值 V′。
- **判断/计算依据**：首次命中是否为该分块自身；距离是否在量程内；正视性是否为正。
- **输出**：覆盖成功概率矩阵 Q；候选价值向量 V′。
- **被哪一步使用**：S5 构造集合函数；S6 在回退与择优时使用 V′。

### S5 预算约束下的待执行站位选定

- **输入对象**：S4 的 Q；S1 的任务分数与面积；S3 的 ℓ(v)；剩余预算 B。
- **执行动作**：以 Q 构造关于站位集合的单调子模覆盖函数；为每个候选赋等效成本
  （可通行路径代价与单站作业耗时的等效量之和）；在 B 内按边际收益与等效成本之比
  作贪心选择。
- **判断/计算依据**：边际增益；等效成本；累计成本不超过 B。
- **输出**：**待执行站位**（一个或多个）。
- **被哪一步使用**：S6 自其中确定本轮执行站位。

> **本步骤不生成路线。** 路线排序是执行规则 A 的一部分，见 5.A 权 3。

### S6 确定本轮执行站位并获取新增观测

- **输入对象**：S5 的待执行站位；S3 的 ℓ(v)；剩余预算 B；S4 的 V′。
- **执行动作**：按预设执行规则，自所述待执行站位中确定本轮执行的站位；
  **所确定的本轮执行站位须满足 ℓ(v) ≤ B**，即为剩余预算内可达的候选补充扫描
  站位；移动至该站位并重新采集。
- **判断/计算依据**：ℓ(v) 与 B 的比较；预设执行规则。
- **输出**：本轮执行站位 v_k；新增点云 P_k；本轮消耗量。
- **被哪一步使用**：S7a、S7b 处理 P_k；S8 扣减预算。

> **两阶段回退**（待执行站位中无可达者时改从全部可达候选中择优）**不写入
> 权 1**，见 5.A 权 2。权 1 只要求"本轮执行的站位是预算内可达的"这一结果性
> 约束，不限定达成该结果的具体途径。

### S7a 在线发现模型外遮挡物

- **输入对象**：P_k；设计模型三角面集合 T。
- **执行动作**：对每个回波点 x 计算 d(x,T)=min_{t∈T} d(x,t)；保留同时满足
  d(x,T) > ε 与高度大于 z₀ 者，构成模型外表面点集；按预设边长体素化得 U_k。
- **判断/计算依据**：d(x,T) 与 ε 的比较；高度与 z₀ 的比较。**本步骤只需最小距离的
  数值，不需确定由哪个三角面取得；并列不影响阈值判定。**
- **输出**：模型外遮挡体素集合 U_k（可为空）。
- **被哪一步使用**：S8 并入 M_plan。

### S7b 新增观测的配准可用性判定（可选）

- **输入对象**：v_k 的可见掩码；此前各已执行站位的累计可见掩码。
- **执行动作**：统计实际重叠比例与重叠点数；对重叠区域构造点到面信息矩阵并取
  其条件数的单调变换作为几何退化度；据预设条件判定 P_k 是否可用。
- **判断/计算依据**：实际重叠比例是否低于预设下限。
- **输出**：可用性标志；不可用时记录 v_k 为失败站位。
- **被哪一步使用**：S8 决定是否以 P_k 更新证据；失败站位在后续 S3 中用于剔除
  候选（由从属权引入）。

### S8 更新与重新规划

- **输入对象**：U_k；可用性标志；P_k；当前 M_plan、缺口证据、B。
- **执行动作**：
  (a) M_plan ← M_plan ∪ U_k，**U_k 中的体素不建立与任何表面分块的归属关系**；
  (b) 若 P_k 可用，以其重算关联与全部缺口证据；否则不以其更新证据；
  (c) 自 B 扣减本轮消耗；
  (d) 若 B 仍允许且仍存在缺口分块，返回 S3。
- **输出**：更新后的 M_plan、缺口证据、B。
- **被哪一步使用**：S3、S4。

## 4.2 核心闭环与断点检查

```
设计模型 T + 已采集点云 P₀
   │ S1
   ▼  缺口证据与分数
   │ S2 → S3
   ▼  候选站位 V + 可通行路径代价 ℓ(v)
   │ S4（读 M_plan）
   ▼  覆盖成功概率 Q + 候选价值 V′
   │ S5
   ▼  待执行站位（一个或多个）
   │ S6（按预设执行规则；须为预算内可达）
   ▼  本轮执行站位 v_k + 新增点云 P_k
   ├── S7a ──► U_k ──► S8(a) M_plan 更新 ──────► 回灌 S4
   └── S7b ──► 可用性标志 ──► S8(b) 证据更新 ──► 回灌 S1/S3
                    └──► 失败站位 ──► 后续 S3 的候选剔除（从属权）
```

| 相邻步骤 | 前一步输出 | 后一步消费对象 | 一致 |
|---|---|---|---|
| S1→S3 | 分块 + 分数 + 面积 | 分组取样 | ✅ |
| S2→S3 | 自由空间 F | 投影、路径代价、可达性 | ✅ |
| S3→S4 | 候选集合 V | 射线求交 | ✅ |
| S3→S5 | ℓ(v) | 等效成本 | ✅ |
| S3→S6 | ℓ(v) | 预算内可达判定 | ✅ |
| S4→S5 | Q | 子模集合函数 | ✅ |
| S4→S6 | V′ | 择优（回退时） | ✅ |
| S5→S6 | 待执行站位 | 按执行规则择一 | ✅ |
| S6→S7a | P_k | 最近距离计算 | ✅ |
| S6→S7b | v_k 可见掩码 | 重叠比例 | ✅ |
| S7a→S8 | U_k | 并入 M_plan | ✅ |
| S7b→S8 | 可用性标志 | 证据更新开关 | ✅ |
| S8→S4 | 更新后的 M_plan | 下一轮射线求交 | ✅ |
| S8→S3 | 更新后的证据、B | 目标筛选、预算 | ✅ |

**无断点。** 闭环必要性：S7a 的输出唯一去向为 S8(a)，S8(a) 的唯一消费者为下一轮
的 S4；若不重复执行 S3–S7，S7a 不产生任何作用。

## 4.3 冻结的发明点

| 编号 | 内容 | 判定 |
|---|---|---|
| N1 | 在移动平台可通行约束与剩余预算约束下进行多站补充扫描规划 | 必要 |
| N2 | 根据新增点云发现设计模型之外的实际遮挡物 | 必要 |
| N3 | 将其写入规划用遮挡模型且不作为新的待扫描目标 | 必要（N2 的限定，不可分离） |
| N4 | 用更新后的遮挡模型重新计算后续候选的可见性 | 必要 |
| N5 | 以新增观测更新缺口证据并重复规划 | 必要 |
| **N6′** | **本轮执行站位须为剩余预算内可达的候选站位** | **必要**（结果性约束，上位） |

**N6′ 的层级说明**：上一版将"两阶段回退"整体列为必要特征。本版按发明人决定拆为
两层——**结果性约束**（本轮执行站位必须预算内可达）进入权 1，**具体达成途径**
（预选站集中无可达者时改从全部可达候选中择优）降为从属权。

这样处理的理由是防止规避：若权 1 写死两阶段回退，竞争方案只需**从一开始就在全部
可达候选中选择**，即可在不经过"预选—回退"两阶段的情况下达到同样效果而不落入权 1。
上位为结果性约束后，无论采用两阶段回退还是一步到位的可达候选择优，均落入权 1。

**次级发明点（从属权）**：N7 目标分块按构件分组；N8 二维半可通行图；N9 单源最短路
距离场；N10 配准可用性判定与失败站位剔除；N11 执行规则 A/B/C；N12 两阶段回退。

**只进说明书**：配准支持评分项；公式三项的步内归一；障碍栅格的两种标记方式；
规划几何与评测几何分离；一切数值。

# 阶段 5：两套权利要求结构

## 5.A 宽保护方案（主稿）

### 权利要求 1（独立权）

一种补充扫描规划方法，其特征在于，包括：

**S1** 依据设计建筑信息模型与已采集点云，确定所述设计建筑信息模型的表面分块的
缺口证据与任务分数；

**S2** 依据所述设计建筑信息模型中构件的平面占位与高度信息，以及移动平台的尺寸，
构建所述移动平台的可通行空间；

**S3** 依据所述缺口证据，在所述可通行空间内生成多个候选补充扫描站位，并确定自
当前位姿至各候选补充扫描站位的可通行路径代价；

**S4** 依据规划用遮挡模型，计算各候选补充扫描站位对各表面分块的可见性，并据以
确定各候选补充扫描站位的价值；所述规划用遮挡模型的初始内容为所述设计建筑信息
模型的表面；

**S5** 在包含所述可通行路径代价与单站作业耗时的剩余预算约束下，自所述候选补充
扫描站位中选定一个或多个待执行站位；

**S6** 按照预设执行规则，自所述待执行站位中确定本轮执行的站位，所确定的本轮执行
的站位为所述剩余预算内可达的候选补充扫描站位；移动至该站位并获取新增点云；

**S7** 计算所述新增点云中各回波点至所述设计建筑信息模型全部表面的最近距离，将该
最近距离大于预设距离阈值、且高度大于预设地面高度阈值的回波点判定为模型外表面点，
并对判定所得的模型外表面点集合作体素化；

**S8** 将所述体素化所得的体素并入所述规划用遮挡模型，且不为所述体素建立与任何
表面分块的归属关系；以所述新增点云更新所述缺口证据；扣减所述剩余预算；并在
所述剩余预算允许且仍存在缺口的表面分块时，以更新后的规划用遮挡模型与缺口证据
重新执行 S3 至 S7。

### 从属权利要求

**2.**（N12 两阶段回退）根据权利要求 1 所述的方法，其特征在于，S6 中确定本轮执行
的站位包括：自所述待执行站位中取所述剩余预算内可达者；当所述待执行站位中不存在
所述剩余预算内可达者时，自全部所述剩余预算内可达的候选补充扫描站位中，取价值
最高者作为本轮执行的站位。

**3.**（N11-A 执行规则 A，含路线排序）根据权利要求 1 或 2 所述的方法，其特征在于，
所述预设执行规则为：对所述待执行站位进行路线排序，生成一条开环路线，并执行所述
开环路线中的首个站位。

**4.**（N11-B）根据权利要求 1 或 2 所述的方法，其特征在于，所述预设执行规则为：
执行在选定所述待执行站位的过程中，按边际收益与等效成本之比首先被选取的站位。

**5.**（N11-C）根据权利要求 1 或 2 所述的方法，其特征在于，所述预设执行规则为：
执行使当前单步目标函数增量最大的站位；所述单步目标函数中的收益项以本轮各候选的
收益增量最大值归一，路径项以本轮各候选的可通行路径代价最大值归一。

**6.**（N7）根据权利要求 1 所述的方法，其特征在于，S3 中生成候选补充扫描站位之前，
先将所述表面分块按其所属构件分组，每一构件取不超过预设条数的表面分块构成目标
分块集合，且所述目标分块集合的容量随所述设计建筑信息模型中构件的数量缩放；所述
候选补充扫描站位依据所述目标分块集合中各表面分块的位置与法向生成。

**7.**（N8）根据权利要求 1 所述的方法，其特征在于，S2 中所述可通行空间为二维半
栅格；顶面高度不大于预设跨越高度的构件不标记为障碍；底面离地净空大于所述移动
平台高度的构件不标记为障碍；带电构件按其对地安全距离追加标记；已标记的栅格按
所述移动平台的半径作膨胀。

**8.**（N9）根据权利要求 1 所述的方法，其特征在于，S3 中通过自当前位姿在所述可
通行空间上作一次单源最短路求解，一次性获得至所述可通行空间内全部位置的可通行
路径代价，据以确定各候选补充扫描站位的可通行路径代价。

**9.**（N10 配准可用性判定与失败站位剔除，自包含）根据权利要求 1 所述的方法，
其特征在于，还包括：依据本轮执行的站位所观测到的表面与此前各轮执行的站位所观测

## 5.B 稳创造性方案（备用）

在 5.A 权 1 的基础上，将下列特征上提至独立权：

- 将权 3 的**路线排序与执行首站**并入 S6；
- 将权 2 的**两阶段回退**并入 S6；
- 在 S8 中显式写出"以更新后的规划用遮挡模型重新计算后续候选补充扫描站位的
  可见性"。

| 上提的特征 | 为什么创造性可能更稳 | 因此牺牲的保护范围 |
|---|---|---|
| 路线排序与执行首站 | 使"选定多站—排序—执行首站—重规划"形成完整因果链，链条更闭合，与"每次只算一个视点"的在先方案区别更显性 | 放弃对执行规则 B、C 的覆盖 |
| 两阶段回退 | 把"预选—回退"这一特有的两阶段结构写死，规避解释空间更小 | 一步到位在全部可达候选中择优的实施方式落到范围之外 |
| 显式回灌关系 | 杜绝"发现了但不用于后续计算"的规避解释 | 几乎不牺牲——该关系本属 N4 |

### 关于两套方案的取舍论证（修订）

**上一版的论证已作废。** 上一版写"由于 A/B/C 在真实建筑上性能接近，所以 A 的
创造性增益很小"——这一推论不成立：实验性能差异与专利创造性不是同一判断，实验
只能说明**当前没有充分证据证明策略 A 在真实场景具有明显性能优势**，不能据此判断
A 是否构成区别于现有技术的关键特征。

**正确的取舍论证**：在现有技术检索尚未证明执行策略 A 是区别现有技术的关键特征
之前，独立权采用上位的"预设执行规则"，以避免不必要的限缩；若代理人后续检索认为
策略 A 对新颖性或创造性具有关键贡献，再将 A 上提至独立权，形成 5.B 稳创造性版本。

**因此当前以 5.A 为主稿，5.B 作为检索结果出来后的退守方案。**
