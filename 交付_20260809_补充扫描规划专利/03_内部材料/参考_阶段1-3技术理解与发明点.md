## A. 对旧方案（母专利，公式 1–25）的理解

**一句话**：给定 IFC 模型与已采集点云，找出模型表面上"没被扫到或扫得不够"的地方，
并给出下一个补充扫描视点。**[A]**

**技术链**：
IFC 三角网 → 按法向区域生长切分为表面分块 → 点云最近邻关联到分块 →
逐分块统计观测量（点数、点密度、有效视角数、最佳正视性）→ 归一为缺口证据
（观测缺口 D_obs、角度缺口 D_ang、几何缺口 D_geo、语义缺口 D_sem、材料缺口）→
加权融合为缺口分数 G_gap → 乘工程重要度得任务分数 G_task → 在分块周围按固定
距离档生成候选视点 → 按可见性、正视性、距离质量、分辨率质量、面积、缺口分数
计算视点价值 → 取价值最高者 → 执行后更新证据，形成闭环。**[A]**

**输入**：IFC 模型（含构件语义与材料）、已采集点云。
**输出**：单个补充扫描视点。**[A]**

**旧方案的边界**：输入是模型与点云，输出是一个视点。**不涉及**移动平台、可通行性、
多站路线、路径或作业时间预算，也**不涉及**在作业过程中修正遮挡模型本身。**[A]**

## B. 对新方案的理解

**一句话**：在移动平台可通行约束与路径／作业时间预算下，组织一条包含多站的补充
扫描路线；并在执行过程中，用已测点云在线修正"设计模型里没有、现场却存在"的遮挡
物，使后续视点的可见性预测不再重复同一错误。**[A]**

**新增的技术链（在旧链之后接入）**：

```
S1 证据构建（沿用旧方案 1–25）
      ↓ 输出：逐分块的缺口分数 G_gap、任务分数 G_task、面积、法向、形心
S2 可通行图构建
      ↓ 输出：二维半栅格上的自由空间（布尔栅格）
S3 候选生成
      ↓ 输出：候选站位集合，每个带"当前位姿到该站的最短路径长度"
S4 视点评估（对规划用遮挡模型求交）
      ↓ 输出：每个候选对每个分块的覆盖成功概率 q'、候选价值 V'
S5 站集选择与排序
      ↓ 输出：预算内的站集与其开环路线
S6 执行一站并重新采集
      ↓ 输出：新增点云
S6a 在线遮挡发现 → 输出：修正后的规划用遮挡模型（回灌 S4）
S6b 配准判定     → 输出：该站数据可用 / 作废（作废时其站位回灌 S3 的去重集）
S7 更新证据（回灌 S1）→ 回到 S3
```

**闭环的必要性判断**：闭环是**技术方案的必要组成**，不是进一步优化。**[B]**
理由：S6a 的输出（修正后的遮挡模型）必须回灌 S4 才有意义；若只执行一轮，S6a 不
产生任何作用。这一点在实验上可验证——n_temp=0（模型与实景一致）时，含 S6a 的
方法与不含 S6a 的方法逐位相同 **[A]**（`tests/test_occluder_discovery.py`）。

## C. 新旧方案的技术差异（逐条给出"问题 → 手段 → 效果"三段式，按指导 §12）

### C1 现场存在设计模型里没有的遮挡物

- **旧方案的问题**：视点价值中的可见性由模型几何求交得到。竣工现场普遍存在施工
  车辆、材料堆放、脚手架、临时围挡等设计模型中不存在的物体，它们遮挡扫描仪却不
  遮挡基于模型的求交，于是可见性被**系统性单向高估**；由于遮挡模型不被修正，同一
  预测错误在闭环的每一轮重复发生。**[A]**
- **本方案的手段**：S6a。计算本站回波点至全部设计模型曲面的最近距离，将该距离
  大于预设距离阈值、且高度大于预设地面阈值的回波点判定为"已测到但模型中不存在
  的表面"；对该点集按预设边长体素化，所得体素并入**规划用遮挡模型**；该体素不
  引入新的待扫目标（构件归属置空）。**[A]**
- **技术效果**：可见性预测的平均绝对误差降低 **2.7–8.7 倍**（三个种子，
  `results/evidence/discovery_vis_error.json`，commit `c631abc`）。**[A]**
- **须一并记载的代价**：体素外扩使误差由单向高估变为双向；上述三种子的低估条目
  由 0 分别增至 132、242、188 条。**[A]**

### C2 剩余预算不足时整个任务提前终止

- **旧方案的问题**：旧方案只输出一个视点，没有预算概念，因此没有这个问题；但一旦
  引入"整条路线的预算"，集合选择依据的是整条路线的等效成本，而每轮只执行一站，
  两者只在恰好选满时等价。选少了，被选中的站集可能没有任何一站在剩余预算内可达。
  **[A]**
- **本方案的手段**：S7。本轮执行的站位限制在剩余预算内可达的候选之中；当所选站集
  中不存在可达站位时，退而在预算内可达的全部候选中选取价值最高者，而非终止流程。
  **[A]**
- **技术效果**：路径预算 400 / 60 / 25 m 分别得到 6 站（缺口加权恢复率 0.988）、
  3 站（0.817）、1 站（0.638），恢复率随预算单调下降；未设该回退时 25 m 预算下为
  **0 站、恢复率 0.000**，而彼时预算内可达候选有 202 个。**[A]**
  （`tests/test_scene_families.py::test_tight_budget_degrades_instead_of_collapsing`）

### C3 配准失败的站位被反复重选

- **旧方案的问题**：旧方案不涉及配准成败判定。引入该判定后，失败站的数据整体作废
  并从已执行站集中剔除，于是它不再出现在候选去重集里；而移动平台已经在该点，其
  路径代价为零、成本全局最低，比值贪心必然重复选中同一位置。**[A]**
- **本方案的手段**：S8。将判定为失败的站位与已成功执行的站位**一同**加入候选
  去重集。**[A]**
- **技术效果**：修复前六轮全部停留在同一位置、恢复率 **0.000**；修复后访问 6 个
  不同位置，在一站失败的情况下恢复率达 **0.876**。**[A]**

### C4 小型设备得不到任何为其生成的候选视点

- **旧方案的问题**：目标分块集按"缺口分数×面积"排序并按固定条数截断。面积在同一
  站场内跨约两个数量级，而工程重要度系数仅跨 1.0–1.3，**重要度在排序中永远压不过
  面积**，截断边界恰好落在小型设备尺寸上。**[A]**
- **本方案的手段**：S3 的一部分。目标分块集按所属构件分组，每构件取不超过预设条数
  的分块，且集合容量随构件数量缩放。**[A]**
- **技术效果**：修复前即使在最小规模场景中，隔离开关 0/144、电流电压互感器 0/72、
  避雷器 0/72、绝缘子 0/20 均无任何候选视点（大规模场景 0/576、0/288、0/288、
  0/40）；修复后全部构件与全部设备类别 100% 进入目标集。**[A]**

### C5 现场几何与规划所依据的模型不是同一份

这是 C1 的**验证方法论**，不是产品侧动作。产品中规划器本来就只有设计模型。
按指导 §12 的要求单列，但**不作为发明点**，见 E 节。**[B]**

## D. 完整数据流与步骤链（按指导 §8 检查闭合性）

| 步骤 | 输入对象 | 执行的动作 | 判断/计算依据 | 输出，及下一步如何使用 |
|---|---|---|---|---|
| S1 | 设计模型三角网、已采集点云 | 切分表面分块；点云关联到分块；统计并归一为缺口证据；融合 | 沿用母专利公式 1–25 | 逐分块的 G_gap、G_task、面积、法向、形心 → S3 选目标、S4 算收益 |
| S2 | 设计模型构件的平面包围盒或三角面、底面净空、对地安全距离 | 标记障碍、安全膨胀、按平台半径作距离变换膨胀 | 构件顶面高度是否低于跨越高度；净空是否大于平台高度 | 自由空间布尔栅格 → S3 投影候选、算路径长度 |
| S3 | S1 的分块与分数、S2 的自由空间、已执行站位与失败站位 | 目标分块按构件分组取样；在目标周围按距离档与栅格节点生成候选；投影至自由空间；剔除去重集邻域内者；一次单源最短路求全部路径长度 | 每构件不超过预设条数；容量随构件数缩放；去重半径 | 候选站位集合 + 各自路径长度 → S4 评估 |
| S4 | S3 的候选、S1 的分块、规划用遮挡模型 | 逐候选对各分块作首次命中求交；算正视性、量程—密度质量；合成覆盖成功概率与候选价值 | 公式(27)(28)(31)(33)(35)(41) | q'（候选×分块矩阵）、候选价值 → S5 |
| S5 | S4 的 q' 与价值、S3 的路径长度、剩余预算 | 以覆盖概率构造单调子模集合函数，按性价比贪心选站；对所选站集求开环路线 | 边际收益/等效成本比值；预算约束 | 站集与路线 → S6/S7 |
| S6 | S5 的路线首站 | 移动并重新采集 | — | 新增点云 → S6a、S6b、S1 |
| S6a | S6 的回波点、设计模型曲面 | 算最近距离；筛出超阈值且高于地面阈值者；体素化；并入规划用遮挡模型 | 距离阈值 ε、地面高度阈值、体素边长 | 修正后的规划用遮挡模型 → **回灌 S4** |
| S6b | S6 的新站可见掩码、既有覆盖 | 算实际重叠比例与重叠区几何退化度；判定能否拼入全局坐标系 | 重叠比例是否低于下限 | 可用/作废；作废站位 → **回灌 S3 去重集** |
| S7 | S1 证据 + S6 新增点云 | 重算关联与全部证据 | 沿用 S1 | 更新后的 G_gap → 回到 S3 |

**闭合性检查结论**：S1→S7 每一步的输出都被下一步显式消费，无"输出 A 而下一步用 B"
的断点。**[A]**

## F. 当前存在的技术歧义与潜在代理人疑问

### F1 【D】"最近距离"的计算对象与并列处理未在权项层面确定

S6a 判据为"回波点至全部设计模型曲面的最近距离大于 ε"。代理人会问：
- 最近点可能落在三角面内部、边上还是顶点？
- 多个曲面同时达到最小距离怎么办？
- 浮点下如何判断"相同"？

**现状**：实现调用 Open3D 的无符号距离场，**未实现确定性并列裁决规则** **[A]**。
母专利第三轮答复中已为"点—构件关联"实现过一套确定性并列裁决
（`src/patent_gap/data/tie_break.py`：距离 → 正视性 → 几何字典序顶点键 → 构件
GlobalId）**[A]**。

**须发明人确认**：S6a 的距离判据是否也采用该套规则？若是，说明书应引用；若否，
应说明为何此处不需要（例如"判据是阈值比较而非择一，并列不影响结果"）。
按指导 §4，若方案声称"唯一、稳定、可复现"，裁决规则不能依赖不稳定的存储顺序。

### F2 【D】体素并入后可能把"实际可见"预测为"不可见"

实测：并入发现体素后，高估条目由 502/381/407 降至 10/0/19，但**新增低估条目
132/242/188**，其中部分把真实可见率大于 0.5 的目标预测为全遮 **[A]**。成因是体素
边长带来的外扩。

**须发明人确认**：是否需要在权利要求或说明书中加入抑制外扩的措施（例如仅对被多站
一致判定为"测到但模型中没有"的体素并入、或按点密度设置体素占据阈值）？
**现有材料不足以确认实现中是否有此类措施——代码中没有，不能写死。**

### F3 【A】配准感知项在两类场景下的数值行为完全不同，且对决策无影响

- 合成变电站：重叠区退化度中位 0.984，配准支持项约占候选价值的 1%，六轮闭环中
  **一次都没有改变过最高价值候选** **[A]**。
- 真实建筑：同一项占约 25% **[A]**。
- 但把该项权重置零后，闭环结果**逐位不变** **[A]**（`results/e6_ablation.log`）——
  因为集合选择消费的是覆盖概率矩阵与收益向量，不消费候选价值。

**结论**：I5 的技术方案清楚可实施，但**目前没有任何实验证据支持它带来效果**。
按指导【原则1】，不得把 C 类伪装成 A 类。效果段只写机理。

### F4 【D】"构件"的口径

构件等权恢复率中的"构件"是**建模图元**（一台主变对应箱体与 4~6 片散热片共 5~7 个
图元，三相断路器对应 3 个）**[A]**，不是设备台数。若说明书写作"每台设备等权"，
即与实现不符。

**须发明人确认**：是否需要引入设备级标识（例如按 IFC 的 IfcElementAssembly 或
自定义分组）以对齐验收口径？**现有材料中合成场景未建模设备级分组。**

### F5 【D】真实数据上多出来的机制反而略差

真实建筑上，只含遮挡与量程感知的方法（0.973/0.981/0.974）略高于含集合选择与
配准项的完整方法（0.959/0.981/0.956）**[A]**。已排除三个嫌疑：重叠率硬约束
（1237 个候选只剔除 4 个）、配准项权重（置零逐位不变）、执行策略（三种相同）
**[A]**。差异落在集合选择的目标函数本身，量级为 1.5 个百分点，**一栋楼、一个种子**。

**须发明人确认**：是否在提交前补充更多真实场景？否则说明书中关于"集合选择带来
增益"的表述只能依据合成场景（该处证据充分，见下）。

### F6 【A】E6 的产物 commit 戳不精确

提交"，但确切代码无法由该戳恢复。**须在任何引用该批结果处一并声明。**

## G. 在开始撰写权利要求正文前，必须由发明人回答的问题

按指导要求，只列真正影响技术方案成立的事项。

   说明其技术效果。
4. **"构件等权"是否要对齐到设备台数？**（见 F4）
   —— 影响有益效果的表述口径与说明书是否需要新增分组步骤。
5. **执行策略 A/B/C 采用哪种权项结构？**（见 E 节末）
   —— 这是权项布局问题，建议方案 2（上位 + 从属分列），但应结合检索结果。
6. **母专利目前是否已公开、是否已构成本申请的抵触申请？可否主张其优先权？**
   —— 直接决定本申请能否作为独立申请提交，以及是否需要调整权 1 的上位层级。
