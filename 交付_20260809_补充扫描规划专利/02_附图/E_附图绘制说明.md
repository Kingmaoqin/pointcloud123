配套图件已生成于 `02_附图/`，每幅同时提供矢量（`.svg`，供正式申请稿排版）与位图
（`.png`，供审阅），另有 `附图.docx` 内嵌全部六幅。生成脚本为 `附图生成脚本.py`。

**本说明与图件为同一版本。** 上一版的图 1（S7a 在 S7b 之前）与图 3（沿分块整段
外扩的壳带）已作废，本说明的对应两节已同步重写。

**总体要求**：不阅读正文、只看图与图例，应基本知道图表达的关系。图中不出现任何
代码路径、提交标识或数值实验结果。

## 图 2　可通行空间构建示意图

| 项 | 内容 |
|---|---|
| **图名** | 可通行空间构建 |
| **必须出现的对象** | 四类构件各一例：构件 A 普通障碍；构件 B 带电构件；构件 C 顶面不大于跨越高度；构件 D 底面净空大于平台高度 |
| **箭头方向** | 构件 D 处一条双向箭头，标注其底面净空与平台高度的比较 |
| **线型/阴影含义** | 实心填充＝障碍栅格；斜线阴影＝带电构件按对地安全距离追加标记的禁入栅格；点线外框＝对已标记栅格（障碍与禁入）按平台半径的膨胀；细实线框＝未标记为障碍的构件（其外**不画**膨胀框）；白色＝自由空间 |
| **关键标签** | "构件C 顶面≤跨越高度 不标记为障碍"、"净空>平台高度 不标记为障碍"、"可从下穿行"、"带电体安全距离标记" |
| **容易画错的地方** | ① 带电构件应画**三层**：最内层构件本体、中间层电气安全距离禁入区、最外层在禁入区基础上再按平台半径的膨胀。只画两层会误导为"安全区不参与膨胀"；② 未标记为障碍的构件（C、D）**其外不得画膨胀框**——既然不是障碍就不会被膨胀，画了会自相矛盾；③ 障碍、禁入、膨胀是三种不同性质的标记，不得用同一种阴影 |

## 图 3　候选补充扫描站位与距离层示意图

| 项 | 内容 |
|---|---|
| **图名** | 候选补充扫描站位与距离层 |
| **必须出现的对象** | 一个有限长的目标表面分块；其形心（明确标出的点）；自形心出发的单位法向箭头；围绕法向的锥形范围两条边界线；三个距离层 d1／d2／d3；保留的候选与被剔除的候选；一个经自由空间投影后偏离距离层的候选 |
| **箭头方向** | 自形心指向法向侧的单箭头，标"法向 n" |
| **线型/阴影含义** | 粗实线＝目标表面分块；实心小点＝形心；点划线＝法向锥的两条边界；灰带＝距离层；虚线＝层中心距离；实心圆＝保留的候选；空心圆＝被剔除的候选 |
| **关键标签** | "目标表面分块"、"形心"、"法向 n"、"法向锥（方位角偏置范围）"、"距离层 d1／d2／d3"；图下方两行图例 |
| **容易画错的地方** | ★ **距离层的几何**。候选位置由"分块形心 + 距离档 × 方向"确定，方向为该分块单位法向经方位角与俯仰角偏置旋转所得。因此距离层是**以分块形心为球心、以距离档为半径、限制在法向锥内的球面区段**，平面投影中表现为围绕形心的圆弧带。**不得画成沿分块整段外扩的壳带**（那对应"到整片分块的等距轨迹"，与本方法的候选生成方式不符）；**也不得画成完整同心圆**（候选被限制在法向锥内，背面与侧向没有候选）。另：本图只画目标导向候选，S3 另由自由栅格节点生成的候选不在图中示出，须在图例注明；候选经自由空间投影后可偏离距离层中心线，应至少画出一个并标注，否则读者会以为最终站位必须严格落在距离层上 |

## 图 4　在线发现模型外遮挡物示意图

| 项 | 内容 |
|---|---|
| **图名** | 在线发现模型外遮挡物（上：并入发现体素之前；下：并入之后） |
| **必须出现的对象** | 上下两幅子图，各含：候选站位、目标表面分块、模型外遮挡物（现场存在）；下幅另含发现体素 |
| **箭头方向** | 自候选站位指向目标表面分块的射线。上幅贯通至分块；下幅在发现体素处终止，终止处画一短粗横杠表示阻断 |
| **线型/阴影含义** | 交叉阴影实体＝模型外遮挡物（现场存在的实物）；点线方格＝发现体素；粗实线段＝目标表面分块；实心圆＝候选站位 |
| **关键标签** | 上幅："射线在规划用遮挡模型上无阻断 → 预测为可见"，以及"交叉阴影块仅表示真实现场中客观存在的物体；并入发现体素之前，该几何不属于规划用遮挡模型"；下幅："射线被发现体素阻断 → 预测为不可见"，以及"满足 d(x,T)>eps 且高度>z0 的回波点 → 体素化 → 并入规划用遮挡模型"、"点线方格＝发现体素（不携带分块归属，只作遮挡体，不是新的待扫目标）" |
| **字符注意** | 图中一律写 `eps`、`z0` 等 ASCII 形式，**不使用 ε、z₀ 等特殊字符与下标**——中文字体常缺这些字形，会渲染成方框 |
| **容易画错的地方** | ① 发现体素必须与目标表面分块用**明显不同**的线型／填充，且必须显式标注"不携带分块归属"——这是"体素只作遮挡体、不作新的待扫目标"这一必要技术特征的唯一图示；② 上幅中现场遮挡物必须画出来（它客观存在，只是不在设计模型里），若上幅不画，读者会以为下幅的体素凭空产生；③ 上下两幅的候选站位与目标分块位置必须完全一致，否则无法对比 |

## 图 5　剩余预算的等代价边界示意图

| 项 | 内容 |
|---|---|
| **图名** | 剩余预算的等代价边界 |
| **必须出现的对象** | 当前位置；若干道带门洞的墙体；等代价边界；预算内可达区域；待执行站位若干（均在边界之外）；回退所选候选一个（在边界之内）；作为对照的同代价欧氏圆 |
| **箭头方向** | 一条指引箭头自图例文字指向门洞处，说明边界在此受墙体约束、只能经门洞向右延伸 |
| **线型/阴影含义** | 粗实线＝等代价边界；细虚线＝同代价的欧氏圆（**对照用，非本方案所用**）；灰区＝剩余预算内可达；实心填充＝障碍；空心三角＝待执行站位；实心圆＝回退所选候选 |
| **关键标签** | "当前位置"、"待执行站位：均在边界之外（剩余预算内不可达）"、"回退所选候选：全部候选中满足 ℓ(v)≤B 且价值最高者"、"门洞：边界受墙体约束，只能经此向右延伸"；图例须写出数学含义"灰区：ℓ(v)≤B　粗实线：ℓ(v)=B　边界之外：ℓ(v)>B" |
| **容易画错的地方** | **★ 本图最易画错之处**：等代价边界**不得**画成以当前位姿为圆心的欧氏圆。它是"自当前位置沿可通行空间的最短路径代价等于剩余预算"的等值线，因此必须：① 在墙体处被截断而非穿墙；② 穿过门洞后在门洞另一侧形成凸出（因为路径必须绕行，同样的代价只能走到更近的直线距离）；③ 与同代价欧氏圆明显不重合。本图中的边界由真实的八邻域最短路距离场计算得到，不是手绘。另：回退所选候选的标注须写明它来自**全部候选**而非原待执行站位集合——这是两阶段回退最关键的技术点 |
