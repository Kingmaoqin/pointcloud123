## 3. 背景技术

工业场站与建筑的竣工测量需要采集覆盖全部目标构件的三维点云。受构件相互遮挡、
站位可达性与作业时间限制，首轮扫描往往在部分表面上留下数据缺口，需要安排补充
扫描。

**第一类现有技术是基于设计模型的离线覆盖规划。** 在作业开始前，依据设计建筑信息
模型的几何对表面可见性求解集合覆盖，一次性解算出一组站位，作业时按该站位序列
依次架设。该类方法的不足在于：其一，站位在作业开始前即全部确定，无法利用作业
过程中已经采集到的数据；其二，也是更根本的，它假定现场几何与设计模型一致。

**第二类现有技术是基于已采集点云的缺口驱动规划。** 检测已采集点云相对设计模型的
缺口，据此评估候选站位并选取最优者，执行后依据新的采集结果更新证据。该类方法
解决了缺口定位问题，但其输入为模型与点云、输出为单个站位，未涉及移动平台的可
通行约束、多站补充扫描的组织、移动路径预算，也未涉及在作业过程中对遮挡模型
本身的修正。

**两类现有技术共同的未解问题**：竣工现场普遍存在设计模型中不存在的物体——施工
车辆、材料堆放、脚手架、临时围挡等。这类物体会遮挡扫描仪，却不会遮挡基于设计
模型的可见性计算，于是可见性被**系统性单向高估**：规划出的站位到现场被遮挡，该
站的架设与作业时间白白付出。更重要的是，由于遮挡模型不被修正，**同一预测错误在
后续每一轮重复发生**——已经用一站的代价"测到"了那个障碍物，这一信息却没有被用于
改进后续规划。

---

## 4. 要解决的技术问题

**问题一**：基于设计建筑信息模型的可见性计算因现场存在模型外遮挡物而系统性单向
高估，且该错误在多轮补充扫描中重复发生，已采集数据中蕴含的障碍物信息未被用于
修正规划所依据的遮挡模型。

**问题二**：在多站补充扫描过程中，每执行一站后当前位置与剩余可通行路径代价预算
均发生变化，前一轮预选的待执行站位中可能不存在其可通行路径代价不大于当前剩余
预算者，从而导致规划流程提前终止并输出零结果；而此时全部候选站位中仍可能存在
满足剩余预算的可达站位。

**问题三**（对应从属权）：以缺口分数与面积之积排序并按固定条数截断目标表面分块集
时，同一场站内表面分块的面积跨约两个数量级，而工程重要度系数的跨度远小于此，
重要度在排序中不能压过面积，致使小尺寸构件得不到任何为其生成的候选站位。

**问题四**（对应从属权）：新增观测因与既有覆盖重叠不足而无法拼入全局坐标系时，
其数据整体作废，该站位随之不再计入已执行的站位；而移动平台恰在该位置、自当前
位置至该位置的可通行路径代价为零，按边际收益与等效成本之比选取时必然重复选中
同一位置。

## 5. 技术方案

### 5.1 总体流程

本发明的补充扫描规划方法包括步骤 S1 至 S8，其数据流为：

```
设计模型 T + 已采集点云 P₀
   │ S1
   ▼
缺口证据与分数（逐表面分块）
   │ S2 → S3
   ▼
候选补充扫描站位 V + 路径长度 ℓ(v)
   │ S4（读规划用遮挡模型 M_plan）
   ▼
覆盖成功概率 Q + 候选价值 V′
   │ S5
   ▼
待执行站位（一个或多个）
   │ S6（按预设执行规则；须为预算内可达）
   ▼
本轮执行站位 v_k + 新增点云 P_k
   ├── S7b ──► 满足预设更新条件？
   │      ├─ 是 ──► S7a ──► U_k ──► S8(a) 更新 M_plan ──────► 回灌 S4
   │      │              └──► S8(b) 更新缺口证据 ──────────► 回灌 S1/S3
   │      └─ 否 ──► M_plan 与缺口证据均保持不变
   │                └──► 记录失败站位 ──► 后续 S3 的候选剔除（权 9）
```

### 5.2 各步骤

**S1 缺口证据与分数构建。** 本步骤含五个子步骤。

**(a) 表面分块切分。** 将设计建筑信息模型的三角面按法向一致性作区域生长：

以未被归入任何分块的三角面为**种子三角面**，记其单位法向为 n_seed，以该三角面
初始化一个正在生长的区域，并将其置入待扩展队列；自队列取出一个**当前三角面**，
记其单位法向为 n_cur；对与该当前三角面**共享边**且尚未归入任何分块的相邻三角面，
记其单位法向为 n_nb，**当且仅当 n_nb 与 n_cur 的夹角、以及 n_nb 与 n_seed 的
夹角同时不超过预设法向阈值时**，将其并入该区域并置入队列；重复至队列为空。

共享边邻接是成为候选并入对象的**前提**；上述**双法向约束**（同时比当前三角面法向
与种子三角面法向）是**判定条件**。二者性质不同：仅与当前三角面比较会使区域沿曲面
逐步漂移，附加与种子的比较限定了整个区域相对种子的法向偏离。

所得区域即表面分块，面积小于预设下限者舍弃。每个表面分块携带形心、单位法向、
面积与所属构件标识。

**(b) 点—表面分块关联。** 对已采集点云中的每个点，确定其所对应的设计模型表面并
据此归入相应表面分块。本实施方式按"点到设计模型三角面的最近距离"确定：距离不
大于预设关联距离阈值者，归入该三角面所属的表面分块；超过该阈值者判为未关联点，
不参与任何分块的统计。**一个点至多归入一个表面分块，不重复计数。** 若多个三角面
同时取得最小距离，采用确定性归属规则择一（实施方式见 8.2）。

**(c) 缺口证据。** 逐表面分块统计观测量并转换为缺口证据。本实施方式采用五类：

| 缺口证据 | 由何观测量合成 | 回答的问题 |
|---|---|---|
| 观测状态证据 D_obs | 该分块是否被直接观测到、有效视角数、投影分辨率质量、配准置信度四项加权 | 这块表面**有没有被有效地测到** |
| 观测角度证据 D_ang | 最佳正视性、有效视角数、角度多样性三项加权后取补 | 只被**掠射角**或单一方向观测到 |
| 几何完整性证据 D_geo | 覆盖率与密度比两项加权后取补 | 扫到了**多大面积**、扫到的地方**够不够密** |
| 遮挡证据 D_occ | 该分块采样点在已执行站位下的最佳可见比例取补 | 被其他构件**遮住** |
| 量程密度证据 D_rng | 实测点密度与该分块所需点密度之比取补 | 相对**该分块的验收要求**密度是否达标 |

**D_geo 与 D_rng 之间存在有意保留的部分重叠，须如实说明**：本实施方式中二者使用
**同一个密度比** r_j（定义见 8.2），即 D_rng = 1 − r_j，而 D_geo 中的密度项亦为
1 − r_j，权重 0.40。因此该密度统计在 G_gap 中被计入两次——一次单独作为 D_rng，
一次作为 D_geo 的一个分量与覆盖率合成。**这不是两个分母不同的独立量。**

保留这一重叠的理由是二者的组合层级不同：D_geo 把密度与**空间覆盖率**合成，回答
"这块表面扫到了多大面积、扫到的地方够不够密"；D_rng 单独给出密度是否达标。
**若某实施方式认为该重叠不可接受，可只启用其中一项**，另一项自可用证据集合 K_j
中剔除，其权重按下式重新归一，不影响其余步骤。

可选地还可采用语义证据与材料证据。**全部缺口证据统一转换为"数值越大表示缺口
越严重"的方向，取值范围 [0, 1]。** 某一项证据不可获得时（例如无材料信息），该项
自可用指标集合中剔除，不按 0 或最大值处理，其权重按 (d) 重新归一。

**(d) 缺口分数与任务分数。** 缺口分数由可用缺口证据加权求和得到：

    G_gap,j = Σ_{k ∈ K_j} w̃_{j,k} · D_{j,k}

其中 K_j 为分块 j 上可用的缺口证据下标集合，D_{j,k} 为第 k 项证据，w̃_{j,k} 为
在 K_j 上重新归一后的权重，即 w̃_{j,k} = w_k / Σ_{k' ∈ K_j} w_{k'}，从而
Σ_{k ∈ K_j} w̃_{j,k} = 1，G_gap,j ∈ [0, 1]。

任务分数在缺口分数基础上按所属构件的**工程重要度** E_j 加权：

    G_task,j = clip( G_gap,j · (1 + λ_imp · E_j), 0, 2 )

其中 E_j ∈ [0, 1] 由所属构件的语义类别按预设对照表给出（实施值见 8.2），
λ_imp 为重要度系数（实施值 0.30，见 8.2）。

**(e) 缺口表面分块的判定。** 当 G_gap,j 不小于预设缺口阈值 τ_gap 时，将表面分块 j
判定为**缺口表面分块**。S3 的目标筛选、S5 集合收益函数的求和范围、以及 S8 中
"仍存在缺口的表面分块"这一循环条件，**均以该判定为准**。

**S2 移动平台可通行空间构建。** 在场地平面上建立分辨率为 res 的二维栅格。

**平面占位**指构件的三维几何在场地水平面上的投影区域。**全部高度量（顶面高度、
底面离地净空、以及 S7a 的地面高度阈值 z₀）均相对于该构件所在作业区域的地面
基准面测量**，不是相对于设计模型的全局坐标原点。

对设计模型中的每个构件：
- 若其顶面高度不大于预设跨越高度 z_step，则视为移动平台可跨越的低矮构件，
  **不将其平面占位标记为障碍**；
- 若其底面离地净空大于移动平台高度 h_robot，则视为移动平台可从其下方穿行，
  **不将其平面占位标记为障碍**；
- 否则，将其平面占位所覆盖的栅格标记为障碍栅格。

对带电构件，**以其平面占位为基础，将与该平面占位的距离不大于其对地安全距离的
栅格追加标记为禁入栅格**。

对全部已标记栅格（含障碍栅格与禁入栅格），按移动平台半径 r_robot 作膨胀；膨胀后
仍未被标记的栅格构成自由空间 F。

**S3 目标分块筛选与候选站位生成。**
(a) **在 S1(e) 判定为缺口表面分块者之中**，按其所属构件分组；每一构件按 G_task 与
面积之积降序取不超过预设条数的分块；所取分块合并为目标分块集合 L_tgt，其容量随
设计模型中构件的数量缩放。**不存在缺口表面分块的构件不参与分组，不会被强制选入
目标分块集合。**
(b) 候选位置初集由两部分构成：
   - **目标导向候选**：对目标分块集合中的每个表面分块，以其形心为起点，取该分块
     单位法向经预设方位角偏置与俯仰角偏置旋转所得的若干方向；沿每个方向按预设
     距离档 d₁, d₂, d₃ 取点。即候选位置 = 形心 + 距离档 × 方向。**所得候选位于
     以该分块形心为球心、以各距离档为半径的球面上，且限制在围绕该分块法向的锥形
     范围内**；
   - **空间多样性候选**：在自由空间 F 上按预设间距取栅格节点。
(c) 将初集中的每个点投影至 F 内距其最近的自由栅格；投影距离超出预设上限者剔除。
**可选地**（对应权利要求 9），剔除与此前各轮执行的站位、或与被判定为配准不可用的
站位之间的距离不大于预设去重阈值 r_dup 的候选。该剔除动作不是本方法的必要步骤，
其技术作用见 6.6。
(d) 自当前位置 v₀ 在 F 上作一次单源最短路求解，得到 v₀ 至 F 内全部自由栅格的
**可通行路径代价**；据此为每个候选赋 ℓ(v)；ℓ(v) 为无穷者剔除。

**关于"可通行路径代价"**：这是一个上位概念，指移动平台自当前位置到达该候选站位
所需付出的代价。**本实施方式中，它取在二维自由空间栅格上计算得到的最短可通行
路径长度，单位为米**；不含坡度、能耗或风险等其他分量。其他实施方式可在该代价中
计入上述分量，本说明书不作限定。

**关于"当前位置"**：移动平台的当前扫描位置。若平台状态以位姿（位置与姿态）表示，
则本实施方式的可通行路径计算**仅使用其位置分量**作为路径起点；姿态不参与路径
计算，亦不参与候选站位评估。

**S4 候选站位评估。** 对每个候选站位 v 与每个表面分块 j：自 v 向 j 的表面采样点
投射射线，在**规划用遮挡模型 M_plan** 上取首次命中；命中 j 自身的采样点占该分块
采样点总数的比例即可见率 Vis(j,v)；结合正视性 f(j,v) 与量程—点密度质量项
g(j,v)，得到覆盖成功概率 q′(j,v)=f·g·Vis；由 q′ 与 G_task、面积合成候选价值
V′(v)。M_plan 的初始内容为设计模型的三角面集合 T。

**S5 预算约束下的待执行站位选定。** 以 Q=[q′(j,v)] 构造关于站位集合的单调子模
覆盖函数 F(S)；对每个候选，以将其加入当前已选集合前后 F(S) 的增量作为边际收益，
以其可通行路径代价与单站作业耗时折算的等效路径代价之和作为等效成本；按边际收益
与等效成本之比作贪心选择，得到**待执行站位**（一个或多个）。

**预算 B 的口径**：B 为**剩余可通行路径代价预算，单位为米，只计移动路径**。单站
作业耗时折算的等效路径代价只出现在上述候选**等效成本**之中，用于避免比值贪心过度
偏好近站，**不构成预算 B 的一部分**。全文（含权利要求、公式、符号表、附图与实施
例）一律采用该口径。

**本步骤不生成路线**；路线排序属执行规则 A 的一部分，见 8.7。

**S6 确定本轮执行站位并获取新增观测。** 以 S5 所得的待执行站位为**优先选择集合**，
按预设执行规则，自满足 ℓ(v) ≤ B 的候选站位中确定本轮执行站位 v_k。

本说明书给出两种途径：
- **两阶段方式**：优先自优先选择集合中取满足 ℓ(v) ≤ B 者；若该集合中不存在满足者，
  则自 S3 的全部满足 ℓ(v) ≤ B 的候选中，按 V′ 取最大的一个。
- **一步方式**：直接在满足 ℓ(v) ≤ B 的全部候选中，按 S5 的选择准则择优。

若两者所依据的集合均为空，则终止流程并记录终止原因。移动至 v_k 并重新采集，得到
新增点云 P_k。

**S7a 在线发现模型外遮挡物（仅在 P_k 满足预设更新条件时执行）。**
对 P_k 中每个回波点 x，计算

    d(x, T) = min_{t ∈ T} d(x, t)

其中 T 为设计模型的三角面集合，d(x, t) 为点 x 到单个三角面 t 的最近欧氏距离。
保留同时满足 d(x, T) > ε 且 x 的高度大于预设地面高度阈值 z₀ 的回波点，构成模型外
表面点集 P_out。对 P_out 按预设边长 a 作体素化，取所得占据体素的集合 U_k。

**S7b 新增观测的配准可用性判定（可选）。** 统计 v_k 所观测到的采样点中同时被
此前各轮执行的站位所观测到者的比例，记为实际重叠比例 O_real，其点数记为 K；对该重叠区域
的采样点及其法向构造点到面信息矩阵，取其条件数的单调变换作为几何退化度 Degen。
若 O_real 低于预设下限 O_min，则判定 P_k **不满足预设更新条件**。

**未执行 S7b 时的缺省**：不进行配准可用性判定的实施方式中，预设更新条件恒为满足，
S7a 与缺口证据更新照常执行。

**S8 更新与重新规划。**
(a) 若 P_k 满足预设更新条件，令 M_plan ← M_plan ∪ U_k。**U_k 中的体素不建立与
任何表面分块的归属关系，即不构成新的待扫描目标；待扫描目标集合始终由设计建筑
信息模型的构件清单确定。**
(b) 若 P_k 满足预设更新条件，则将 P_k 纳入**累计有效观测**（此前各轮满足更新条件
的观测与本轮观测之并集），并基于更新后的累计有效观测重新计算点—分块关联与全部
缺口证据，得到更新后的 G_gap——**历史观测不被替换或丢弃**，覆盖率、有效视角数、
最佳正视性等量本就依赖各已执行站位的累计结果；据以按 S1(d) 更新 G_task；并**按 S1(e) 以更新后的 G_gap 重新判定缺口
表面分块**。**若不满足，则 M_plan、缺口证据、任务分数与缺口表面分块均保持不变**，
并记录 v_k 为失败站位，供后续轮次的候选剔除使用（见权利要求 9）。
(c) 自 B 中扣减本轮消耗的可通行路径代价。**本轮的作业耗时不自 B 中扣减**，因 B
为纯路径代价预算。
(d) 若 B 仍允许且**按 (b) 重新判定后仍存在缺口表面分块**，则以更新后的 M_plan、
缺口证据、任务分数与缺口表面分块返回 S3。

## 8. 具体实施方式

### 8.1 实施环境

传感器参数组取：最小量程 0.5 m，最优距离 10 m，最大量程 60 m，角步长 0.4°，
测距噪声标准差 0.005 m。移动平台取：半径 0.6 m（户外轮式平台）或 0.35 m（室内
三脚架），高度 1.8 m，行进速度 0.5 m/s，单站架设与扫描耗时 180 s。

### 8.2 S1 的实施方式

表面分块的切分采用法向一致性区域生长，**法向夹角阈值取 20°**，分块面积下限取
0.01 m²。

**点—分块关联**：关联距离阈值取 0.05 m。若多个三角面同时取得最小距离，按
"距离 → 该三角面相对该点的正视性 → 三角面顶点坐标的几何字典序 → 所属构件标识"
四级确定性规则择一，从而归属唯一且与数据存储顺序无关。

**各项缺口证据的内部构成与实施值**。下列各量均逐表面分块 j 计算；其中作为质量或
比例使用的归一化量取值截断至 [0, 1]，而视角个数与点密度不是 [0, 1] 量：

| 中间统计量 | 实施方式中的取法 |
|---|---|
| 覆盖率 C_j | 该分块的表面采样点中，被任一已执行站位观测到者所占比例 |
| 是否被直接观测 | C_j > 0.05 |
| 有效视角数 n_view,j | 已执行站位中对该分块的可见率超过 0.2 者的个数。**为非负整数，不是 [0,1] 量** |
| 最佳正视性 f*_j | 各已执行站位相对该分块的正视性中的最大值 |
| 角度多样性 a_j | clip(n_view,j / 4, 0, 1)。**本实施方式中该量由有效视角的个数归一得到，衡量的是视角数量而非方向的分散程度**——四个方向几乎相同的站位仍得 a_j = 1。若需真正度量方向分散程度，应另行引入观测方向之间的角度分布指标；本实施方式未采用 |
| 所需点密度 ρ_req,j | ρ₀ · (1 + λ_E · E_j)，ρ₀ 为参考点密度。**单位为点/m²，不是 [0,1] 量** |
| 密度比 r_j | (该分块关联点数 / 该分块面积) / ρ_req,j，截断至 [0, 1]。**D_geo 的密度项与 D_rng 使用的是同一个 r_j** |
| 投影分辨率质量 | **本实施方式中直接取 r_j**。该名称沿用自在先方案的字段命名，其在本实施方式中的取值即密度比，并非独立的投影分辨率度量 |
| 配准置信度 c_reg,j | 各已执行站位对该分块的配准支持度中的最大值；未启用配准支持项时取中性值 0.5 |
| 最佳可见率 v*_j | 各已执行站位对该分块采样点的可见比例中的最大值 |

由此：

    D_obs,j  = clip( 0.35·[C_j ≤ 0.05] + 0.25·clip((2 − n_view,j)/2, 0, 1)
                     + 0.20·(1 − r_j) + 0.20·(1 − c_reg,j), 0, 1 )
    D_ang,j  = clip( 1 − (0.50·f*_j + 0.30·clip(n_view,j/2, 0, 1) + 0.20·a_j), 0, 1 )
    D_geo,j  = clip( 0.60·(1 − C_j) + 0.40·(1 − r_j), 0, 1 )
    D_occ,j  = 1 − v*_j
    D_rng,j  = 1 − clip( (该分块关联点数 / 该分块面积) / ρ_req,j, 0, 1 )

其中 [·] 为指示函数。该分块无任何观测记录时 D_obs,j 直接取 1。

**各项证据在 G_gap 中的权重取相等值**，并在各分块实际可用的证据集合 K_j 上重新
归一。

**关于两处看似重复的加权，须一并说明**：

1. **有效视角数在本实施方式中被计入三处**：D_obs 的第二项（权重 0.25）、D_ang 的
   第二项（权重 0.30），以及 D_ang 的第三项——角度多样性 a_j 亦由视角个数归一得到
   （权重 0.20）。三者的组合层级不同：在 D_obs 中它与"是否被直接观测、密度比、
   配准置信度"合成，回答"观测是否成立"；在 D_ang 中它与最佳正视性合成，回答"观测
   的角度条件是否良好"。**但 a_j 与 D_ang 第二项均只反映视角个数，二者的区别仅在
   归一基数（4 与 2）**。若某实施方式认为重复，可将 a_j 或 D_obs 的该项移除，权重
   按上述规则在 K_j 上重新归一。
2. **密度比 r_j 被计入两处**：单独作为 D_rng，以及作为 D_geo 的第二项（权重
   0.40）。理由与取舍见上文"D_geo 与 D_rng 之间存在有意保留的部分重叠"一段。
3. **工程重要度既进入 ρ_req 又进入 G_task**。二者作用于不同层级：进入 ρ_req 是
   改变**该构件的验收密度要求**——重要构件要求更高的点密度才算达标，属"合格线"；
   进入 G_task 是改变**规划阶段的任务优先级**——同样欠缺程度下重要构件更值得先扫，
   属"排序权重"。**这是有意的设计，不是同一作用的两次计入。** 若某实施方式只需
   其一，可将另一处的系数取 0。

**工程重要度对照表**（户外场站实施值，为推断取值，可按项目验收要求调整）：
主变压器 1.0；断路器 0.9；隔离开关 0.8；电流电压互感器 0.8；绝缘子 0.7；
母线 0.7；避雷器 0.6；构架 0.4；建筑 0.3；围栏 0.2；杂物 0.1。
建筑类场景另按承重与围护结构、门窗、面层、家具的顺序取值。
**任务分数的重要度系数 λ_imp 取 0.30；缺口阈值 τ_gap 取 0.55。**表面采样点数按 M = clip(ceil(A/a₀), M_min, M_max) 确定，其中 A 为分块
面积，实施值 a₀ = 0.25 m²/点、M_min = 16、M_max = 1024；面内采样位置由 Halton
序列驱动，序列种子由分块标识的稳定摘要给出，使同一分块的任意两次评估得到相同的
采样点。

**M_min 不取更小值的原因**：关键构件的分块面积中位数约 0.25 m²，若 M_min 取 4，
则此类分块的覆盖率只能取 {0, 0.25, 0.5, 0.75, 1} 五个值，而覆盖判据为"当前覆盖
不低于参考覆盖的一半"，分辨率不足。取 16 使覆盖率分辨率细化至 1/16，大面积分块的
物理采样密度不受影响，仍为 4 点/m²。

### 8.3 S2 的实施方式

栅格分辨率 res = 0.25 m；跨越高度 z_step = 0.20 m；带电构件的对地安全距离按电压
等级取，110 kV 实施值 1.5 m。

障碍栅格的标记有两种实施方式：
- **方式一（按构件平面包围盒）**：以构件的轴对齐平面包围盒覆盖的栅格为障碍。
  适用于形状接近长方体的场站设备。
- **方式二（按三角面投影）**：取构件中竖向跨度与 [z_step, h_robot] 相交的三角面，
  将其平面投影覆盖的栅格标记为障碍。适用于形状为 L 形、带洞口或细长的构件。

在一栋真实建筑上比较：方式一得到的自由空间中最大连通区域仅占自由空间的 28%，
方式二为 79%。原因是该建筑中存在 L 形墙体与带门洞的墙体，其平面包围盒会将洞口
连同墙体一并覆盖。

对于建筑类场景，门、窗与洞口构件在通行意义上是通路而非障碍，可列入不标记为障碍
的类别；该取舍属于按场景类型的配置，不改变 S2 的其余步骤。

### 8.4 S3 的实施方式

每构件取不超过 2 个缺口表面分块；目标分块集合容量取 min(max(2×有缺口构件数, 60),
400)。

**裁减规则与其适用范围**：先将全部缺口表面分块按 G_task 与面积之积降序排列，再按
构件取每构件前不超过 2 个（保持上述全局降序），最后截取前若干个至容量上限。
因此当 2×有缺口构件数不超过容量上限时（本实施方式即有缺口构件数不超过 200 时），
按构件取出的分块总数不超过容量，**每一有缺口构件均有分块入选**；当有缺口构件数
超过 200 时，截取会按上述全局降序丢弃末尾，**排序靠后的构件可能无分块入选**。
若某实施方式要求在任何规模下都保证每构件至少一项，应改为先为每一有缺口构件保留
一项、再按上述降序分配剩余名额；本实施方式未采用该改法。
距离档取最优距离的 0.4、0.8、1.4 倍（最优距离 10 m 时为 4 m、8 m、14 m）；栅格
节点候选的间距取 10 m；去重半径 r_dup 取 3 m；投影上限取 2 m。

**上述数值为户外场站的实施值。** 在一栋真实建筑上，房间尺度只有数米，距离档
需改取 1.5 m、3 m、5 m，栅格节点间距改取 3 m，去重半径改取 1 m；否则候选点全部
落入墙体内部而投影失败。这说明上述数值是随场景尺度配置的参数，不是固定值。

单源最短路求解采用八邻域 Dijkstra，对角移动的代价取 √2，且要求对角移动的两个
正交邻格均为自由栅格（防止贴角穿越障碍）。

### 8.5 S4 的实施方式

首次命中查询基于包围体层次结构加速。正视性取分块单位法向与"自分块形心指向站位"
单位向量点积的正部；量程—点密度质量项由该站位在该分块上的期望点密度与所需点密度
之比截断到 [0,1] 得到。

**可选实施方式（不进入权利要求）**：候选价值中可追加一项配准支持项，其值由预期
重叠率与重叠区域几何退化度合成，用于在信息增益相近的候选之间倾向选择配准条件更
好的站位。在本申请的实验中，将该项权重置零后闭环结果逐位不变，因此**本说明书
仅记载其机理，不主张其带来恢复率、路径长度或决策质量方面的增益**。

### 8.6 S5 的实施方式

集合函数取 F(S) = Σ_j G_task_j · A_j · (1 − Π_{v∈S}(1 − q′(j,v)))，其中 A_j 为
分块面积，**求和范围为 S1(e) 判定的缺口表面分块**。该函数单调且子模。边际收益取"将候选加入当前已选集合前后 F(S) 的增量"；等效成本取
ℓ(v) + t_scan · v_move，其中 t_scan 为单站作业耗时、v_move 为行进速度，实施值
180 s 与 0.5 m/s，即等效路径代价 90 m。采用惰性贪心按边际收益与等效成本之比依次选取，得到站位集合 S。

**与单点最优取大**：在满足 cost(v) ≤ B_sel 的候选中，取使一阶收益
Σ_j gains_j · q′(j,v) 最大者，记为 v*；比较 F({v*}) 与 F(S)，若前者更大则改取
{v*} 作为本步骤的输出。该步骤用于恢复预算约束下贪心的近似保证。

**等效成本与预算是两回事。** 预算 B 只计移动路径（单位：米）；t_scan · v_move 这
一项只进入候选之间的比值比较，其作用是防止比值贪心过度偏好近站而反复在原地附近
架站。

B、ℓ(v)、t_scan · v_move 与下式的 B_sel **单位同为米**，不存在量纲不一致。问题在
**组成口径不同**：B 只计移动路径，而候选的等效成本另含单站作业耗时折算的等效路径
量，若直接以 B 作为惰性贪心的累计上限，选到第二站时累计成本就会超出 B 而过早截断。
为此，本步骤内部另设一个**仅用于集合选择的比较阈值**：

    B_sel = B + n_rem · t_scan · v_move

其中 **n_rem = 站位数上限 − 已执行的站位数**；站位数上限是本次补充扫描作业允许
执行的站位总数，与 B 一同在作业开始前给定（实施值见实施例）。

**B_sel 只在 S5 的启发式集合选择内部使用，用于控制入选站位的数量，不是本方法的
剩余可通行路径代价预算，也不参与 S6 的可达判定与 S8 的预算扣减。** S6 与 S8 一律
以 B 为准。

**本步骤的输出为待执行站位（一个或多个），不包含路线。**

### 8.7 S6 的实施方式

预设执行规则的三种具体实现：
- **规则 A（优选）**：对 S5 所得的待执行站位作路线排序，由开环旅行商问题求解器
  给出一条开环路线（求解时限实施值 3 s），执行该路线中的首个站位。**路线排序是
  本规则的组成部分，仅在采用本规则时执行。**
- **规则 B**：执行在惰性贪心选取过程中最先被选中的站位。**本规则不需要路线
  排序。**
- **规则 C**：执行使单步目标函数增量最大的站位；该目标函数按步内极值归一，即
  信息项除以本轮各候选收益增量的最大值、路径项除以本轮各候选可通行路径代价的
  最大值。**本规则不需要路线排序。**

三种规则在合成场景上的对照（3 类场景 × 5 个种子共 45 次运行）：规则 A 的缺口
加权恢复率 0.977、关键构件召回 0.956、路径 153 m；规则 C 相应为 0.967、0.924、
230 m；单位路径增益的差异经 Holm 校正后 p = 0.0006。在真实建筑上，三种规则的
缺口加权恢复率分别为 0.959、0.958、0.958。

据此以规则 A 为优选实施方式。**上述数据说明的是当前实验条件下的性能差异；在真实
建筑上尚无充分证据表明规则 A 具有明显性能优势，故 B 与 C 同样作为可选实施方式
予以记载。**

### 8.8 S7a 的实施方式

距离阈值 ε = 0.25 m；地面高度阈值 z₀ = 0.35 m；体素边长 a = 0.40 m，取与移动
平台半径同量级。参与判定的点数上限取 200000，超出时按固定种子的随机数生成器
均匀抽样，因体素化本身已高度冗余，抽样不改变占据体素集合的主体。

最近距离 d(x, T) 由无符号距离场查询得到。**本步骤只需要该最小距离的数值，不需要
确定由哪个三角面取得该最小值；若多个三角面同时取得该最小值，不影响 d(x,T) > ε
的判定结果。** 仅当某个可选实施方式还要求把该回波点唯一归属至某个构件或三角面时，
才需要引入确定性归属规则。

### 8.9 S7b 的实施方式

实际重叠比例 O_real 取 v_k 所见采样点中同时被此前站位所见者的数量与 v_k 所见
采样点总数之比。几何退化度 Degen = 1 − λ_min/λ_max，其中 λ_min、λ_max 为将
点到面信息矩阵的平移块与旋转块分别按迹归一后所得矩阵的最小与最大特征值。
O_min 实施值 0.30。

**配准失败时新增点云的使用范围。** 判定为不满足预设更新条件，意味着该站的数据
无法可靠地拼入设计模型所在的全局坐标系。此时该站点云中任一回波点的全局坐标同样
不可信，因而**不能据以判定"该点离设计模型表面超过 ε"**——距离判据本身建立在两者
处于同一坐标系的前提上。故本方法在该情形下**不执行 S7a**，规划用遮挡模型与缺口
证据均保持不变，仅记录失败站位并扣减已消耗的路径代价。

若某实施方式中移动平台具备独立于点云配准的可靠全局定位（例如全站仪跟踪或高精度
室内定位），使得该站回波点的全局坐标不依赖配准即可确定，则该情形下 S7a 可以照常
执行；采用该实施方式时应在文件中明确说明所依据的定位来源。**本申请的实施例不属于
该情形。**

可选地，可由重叠点数 K 与 Degen 给出位姿误差的量级估计
σ ≈ σ_floor + σ_meas / √K · √(1/(1 − Degen))，并与预设容差比较；该式为受
Cramér–Rao 下界启发的量级估计，非严格的 Cramér–Rao 下界。

### 8.10 S8 的实施方式

规划用遮挡模型的更新采用：将占据体素展开为独立立方体三角网，与设计模型三角面
合并后重建包围体层次结构；合并后的三角面中，属于发现体素者其分块归属标识置为
"无归属"，从而在 S4 的首次命中判定中只作为遮挡体、不作为命中目标。仅在本轮确有
新增占据体素时才重建，无新增时沿用上一轮的结构。

## 10. 边界情况与异常处理

本节只列真实数据中可能发生、且会影响结果确定性或后续处理的情况。

| 情况 | 处理方式 |
|---|---|
| S3 候选集合为空 | 终止流程并记录终止原因为"无候选" |
| S3 中某候选投影失败（周边无自由栅格） | 剔除该候选，不影响其余候选 |
| S3 中某候选不可达（ℓ(v)=+∞） | 剔除该候选 |
| 优先选择集合中无满足预算者 | 自全部满足预算的候选中择优，不终止 |
| P_k 不满足预设更新条件 | 不执行 S7a；M_plan 与缺口证据均保持不变；记录失败站位；已消耗的路径代价照常扣减 |
| S6 回退时预算内亦无可达候选 | 终止流程并记录终止原因为"无可达候选" |
| S7a 中 P_out 为空（未发现模型外遮挡物） | U_k 为空集，M_plan 不变，不重建包围体层次结构，其余步骤照常 |
| S7a 中 d(x,T) 有多个三角面同时取最小 | 不影响阈值判定，见 8.8 |
| S7b 中 K < 3（重叠点过少） | 判定为不可用 |
| S7b 中 Degen 趋近 1（重叠区完全退化） | 位姿误差量级估计中对 Degen 作上限截断，避免除零 |
| 某分块采样点数不足 6，其信息矩阵不可构造 | 该分块不参与退化度计算 |
| 某分块面积趋近 0 | 由 S1 的面积下限剔除 |
| 某分块的所有采样点均不可见 | q′ 为 0，该分块对该候选无贡献；若候选对全部分块的 q′ 均为 0，剔除该候选 |
| 分母为 0（如覆盖率归一时分块无采样点） | 该分块覆盖率取 0 |
| 规则 C 中本轮各候选的收益增量最大值为 0（例如全部候选均无新增覆盖） | 该归一基准取 1，故归一收益项统一为 0 |
| 规则 C 中本轮各候选的可通行路径代价最大值为 0（例如全部候选均在当前位置） | 该归一基准取 1，故归一路径项统一为 0 |
| 多个候选价值完全相同 | 按候选生成顺序取先者；候选生成顺序由目标分块顺序与距离档顺序确定，而目标分块按标识排序，因此该顺序不依赖存储顺序 |
| 缺口分块数为 0 | S8(d) 的循环条件不满足，正常结束 |
| 预算在首轮即为 0 或负 | 不执行任何站位，记录终止原因为"预算耗尽" |

**关于确定性与可复现**：本方法中涉及随机性的环节仅有两处——表面
采样点的 Halton 序列与 S7a 的点数抽样，二者的种子均由稳定摘要或固定值给出，
不依赖进程内的哈希随机化。候选生成、集合选择与路线求解均为确定性过程。

## 13. 实施例二：真实建筑

**该实施例的实施条件与合成场景不同之处**（均属按场景尺度的参数配置，不改变

**最后一项的原因**：真实建筑的自由空间被墙体分隔为多个互不连通的区域，若在全部

在上述配置下，本方法完整执行 28 站并输出站位与路线，缺口加权恢复率 0.959、构件
等权恢复率 0.981、关键构件召回 0.956。

**本实施例的限制**：该数据集仅提供一份融合后的点云，不含逐站位姿，因此补充扫描
站位的重新采集由射线仿真器在真实设计模型上完成——几何与缺口来自真实数据，重新
采集为仿真。该实施例用于说明本方法能够消费真实设计模型与真实实测点云、流程可
执行，不据此主张本方法在真实建筑上普遍优于其他方法。
