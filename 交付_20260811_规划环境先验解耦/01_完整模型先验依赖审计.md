## 三、逐项细节

### 3.1 S1 —— 可原样保留

`build_scene_patches` 按构件切分表面分块；点—分块关联在仿真路径上用射线命中通道、
在真实数据路径上用最近距离阈值；缺口证据、G_gap、G_task、缺口分块判定全部只依赖
**目标表面自身的属性与实测统计**，不依赖"现场其他物体在哪"。**[A]**

**结论**：S1 使用的正是 M_ref 的本职信息，不构成过强环境先验。本轮只需在专利文本
与代码注释中把"设计模型"明确为"目标参考模型"。

### 3.2 S2 —— 最强的一处 oracle

`build_trav_grid(scene, …)` 遍历 `scene.components`，对每个构件按顶面高度、底面
净空、带电安全距离标记栅格，再按平台半径膨胀。**输入是完整模型，与任何观测无关。**
**[A]**

三个后果：

1. **规划器在第一站执行之前就知道现场每个障碍的平面占位**——这是合作方质疑的核心。
2. **不存在 unknown 状态**：模型中没有构件的地方一律是自由空间，机器人可站可走。
   实际上那里可能有模型未记录的物体。**等同于把 unknown 默认当作 free，且未作任何
   说明。**
3. `world.grid` 在整个闭环中**从不更新**——`run_episode` 中没有任何一处重建它。
   即使 S7a 发现了新的占据几何，可通行空间也不变。**[A]**

### 3.3 S3 —— 本身不读完整模型

候选由两部分构成：目标导向候选（读 S1 的分块形心与法向）与自由栅格节点候选（读 S2
的自由空间）。投影、去重、路径代价均在 S2 的栅格上进行。**其先验强度完全由 S2
决定**，本身无需修改。**[A]**

### 3.4 S4 —— M_plan⁽⁰⁾ 就是 M_ref

```
bim = scene.bim_tri_mask()
plan_oracle = (oracle if bim.all() else OcclusionOracle(…triangles[bim]…))
```

`bim_tri_mask()` 只在存在 `in_bim=False` 构件（即实验注入的临时占位物）时才产生
掩码；**在既有全部正式实验中该掩码恒为全真，于是 `plan_oracle` 直接复用评测用的
`oracle`——即完整模型的全部三角面。** **[A]**

这意味着：现有实验中规划器用于预测可见性的几何，与仿真器用于生成"实际看到什么"的
几何**是同一份**（临时占位物实验除外）。这正是合作方所说的"过强几何先验"。

### 3.5 S7a / S8 —— 接缝已经存在，但基准是全模型

`UnmodeledOccluders` 的基准网格是构造参数，`build_oracle()` 返回"基准 + 发现体素"。
当前传入的是全部 BIM 三角面，因此：

- 判据 `d(x, T) > ε` 中的 T 是**完整模型**，于是"离模型远"被解释为"临时异物"；
- 若基准改为"仅目标表面"，同一判据的语义自然变成"**当前参考模型未描述的环境几何**"
  ——这正是本轮要求的上位化，**且不需要改动判据本身**。**[B]**

S8 目前只把新 oracle 赋回 `plan_oracle`（供 S4），**不触及 `world.grid`（S2）**。
**[A]**

### 3.6 是否已有 occupancy / free / unknown / frontier

**没有。** 全仓检索 `occupancy`、`unknown`、`frontier`，命中均在与规划无关的模块
（材料、网页、语义、点云损伤合成）。`TravGrid` 内部只有 `_obstacle` 与 `_forbid`
两个布尔数组，`_compute_free()` 返回二者之外的全部栅格——**没有第三态**。**[A]**

## 四、Phase 1 的三条判断

1. **M_ref 与 M_plan 当前未分离。** M_plan⁽⁰⁾ 直接等于 M_ref 的全部几何，且 S2 的
   可通行空间完全由 M_ref 生成。**[A]**
2. **完整模型 oracle 从两处进入**：S2 的障碍标记（更强，且从不更新）与 S4 的可见性
   求交（接缝已在，易改）。**[A]**
3. **最小修改可行**，不影响 S1–S8 主链：新增一个观测驱动的占据结构，改 S4 与 S7a 的
   基准几何来源，增加 S8 → S2 的回灌。S1、S3、S5、S6 的算法逻辑不动。**[B]**
