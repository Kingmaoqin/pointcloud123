## 图 3　候选补充扫描站位与距离层示意图

| 项 | 内容 |
|---|---|
| **图名** | 候选站位与距离层 |
| **必须出现的对象** | 一个有限长的目标表面分块；其单位法向；三个距离层 d1/d2/d3；保留的候选与被剔除的候选各若干；候选旁的可通行路径代价标注 |
| **箭头方向** | 自分块中部指向法向侧的单箭头，标"法向 n" |
| **线型/阴影含义** | 粗实线＝目标表面分块；灰带＝距离层（壳带）；虚线＝层中心距离；实心圆＝保留的候选；空心圆＝被剔除的候选 |
| **关键标签** | "目标表面分块"、"法向 n"、"距离层 d1/d2/d3"、各候选旁的"ℓ=…"；图下方图例须写明"灰带＝距离层（沿分块整段外扩的壳，非以形心为圆心的同心圆）" |
| **容易画错的地方** | **★ 本图最易画错之处**：距离层**不得**画成以分块形心为圆心的同心圆。正确画法是"到该分块（作为一条有限长线段／一片有限面）的距离等于 d 的等距轨迹"，其形状为沿分块整段外扩的**壳带**——在分块正对区域为平行直段，仅在两端为圆弧过渡。画成同心圆会让读者误以为候选只围绕一个点分布，且会给出错误的三维几何直觉。另：距离层只画法向侧，背面无候选 |

| **线型/阴影含义** | 交叉阴影实体＝模型外遮挡物（现场存在的实物）；点线方格＝发现体素；粗实线段＝目标表面分块；实心圆＝候选站位 |

## 图 5　剩余预算的等代价边界示意图

| 项 | 内容 |
|---|---|
| **图名** | 剩余预算的等代价边界 |
| **必须出现的对象** | 当前位姿；若干道带门洞的墙体；等代价边界；预算内可达区域；待执行站位若干（均在边界之外）；回退所选候选一个（在边界之内）；作为对照的同代价欧氏圆 |
| **箭头方向** | 一条指引箭头自图例文字指向门洞处，说明边界在此受墙体约束、只能经门洞向右延伸 |
| **线型/阴影含义** | 粗实线＝等代价边界；细虚线＝同代价的欧氏圆（**对照用，非本方案所用**）；灰区＝剩余预算内可达；实心填充＝障碍；空心三角＝待执行站位；实心圆＝回退所选候选 |
| **关键标签** | "当前位姿"、"待执行站位：均在边界之外（剩余预算内不可达）"、"回退所选候选（边界之内，价值最高）"、"门洞：边界受墙体约束，只能经此向右延伸" |
| **容易画错的地方** | **★ 本图最易画错之处**：等代价边界**不得**画成以当前位姿为圆心的欧氏圆。它是"自当前位姿沿可通行空间的最短路径代价等于剩余预算"的等值线，因此必须：① 在墙体处被截断而非穿墙；② 穿过门洞后在门洞另一侧形成凸出（因为路径必须绕行，同样的代价只能走到更近的直线距离）；③ 与同代价欧氏圆明显不重合。本图中的边界由真实的八邻域最短路距离场计算得到，不是手绘 |
