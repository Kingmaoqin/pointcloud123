## 2. 技术领域

本发明涉及三维激光扫描与建筑信息模型应用技术领域，具体涉及一种依据设计建筑信息

## 3. 背景技术

工业场站与建筑的竣工测量需要采集覆盖全部目标构件的三维点云。受构件相互遮挡、
站位可达性与作业时间限制，首轮扫描往往在部分表面上留下数据缺口，需要安排补充
扫描。

**第一类现有技术是基于设计模型的离线覆盖规划。** 在作业开始前，依据设计建筑信息
模型的几何对表面可见性求解集合覆盖，一次性解算出一组站位，作业时按该站位序列
依次架设。该类方法的不足在于：其一，站位在作业开始前即全部确定，无法利用作业
过程中已经采集到的数据；其二，也是更根本的，它假定现场几何与设计模型一致。

**第二类现有技术是基于已采集点云的缺口驱动规划。** 检测已采集点云相对设计模型的
缺口，据此评估候选站位并选取最优者，执行后依据新的采集结果更新证据。该类方法
解决了缺口定位问题，但其输入为模型与点云、输出为单个站位，未涉及移动平台的可
通行约束、多站路线的组织、路径与作业时间预算，也未涉及在作业过程中对遮挡模型
本身的修正。

**两类现有技术共同的未解问题**：竣工现场普遍存在设计模型中不存在的物体——施工
车辆、材料堆放、脚手架、临时围挡等。这类物体会遮挡扫描仪，却不会遮挡基于设计
模型的可见性计算，于是可见性被**系统性单向高估**：规划出的站位到现场被遮挡，该
站的架设与作业时间白白付出。更重要的是，由于遮挡模型不被修正，**同一预测错误在
后续每一轮重复发生**——已经用一站的代价"测到"了那个障碍物，这一信息却没有被用于
改进后续规划。

## 4. 要解决的技术问题

**问题一**：基于设计建筑信息模型的可见性计算因现场存在模型外遮挡物而系统性单向
高估，且该错误在多轮补充扫描中重复发生，已采集数据中蕴含的障碍物信息未被用于
修正规划所依据的遮挡模型。

**问题二**：当补充扫描以多站路线组织并受路径与作业时间预算约束时，站位集合依据
整条路线的预算选出而每轮只执行其中一站，两者仅在恰好选满时等价；剩余预算收紧后，
所选站位集合可能不存在任何一站在剩余预算内可达，导致任务提前终止并输出零结果，
而此时预算内实际仍存在大量可用候选站位。

**问题三**（对应从属权）：以缺口分数与面积之积排序并按固定条数截断目标表面分块集
时，同一场站内表面分块的面积跨约两个数量级，而工程重要度系数的跨度远小于此，
重要度在排序中不能压过面积，致使小尺寸构件得不到任何为其生成的候选站位。

**问题四**（对应从属权）：新增观测因与既有覆盖重叠不足而无法拼入全局坐标系时，
若仅将该站位从已执行站位集合中剔除，则该站位不再出现在候选去重集合中，而移动
平台恰在该位置、其路径代价为零，按性价比选取时必然重复选中同一位置。

## 5. 技术方案

### 5.1 总体流程

本发明的补充扫描规划方法包括步骤 S1 至 S8，其数据流为：

```
设计模型 T + 已采集点云 P₀
   │ S1
   ▼
缺口证据与分数（逐表面分块）
   │ S2 → S3
   ▼
候选补充扫描站位 V + 路径长度 ℓ(v)
   │ S4（读规划用遮挡模型 M_plan）
   ▼
覆盖成功概率 Q + 候选价值 V′
   │ S5
   ▼
站位集合 S + 路线 R
   │ S6
   ▼
本轮执行站位 v_k + 新增点云 P_k
   ├── S7a ──► 模型外遮挡体素 U_k ──► S8(a) 更新 M_plan ──► 回灌 S4
   └── S7b ──► 可用性标志 ──► S8(b) 更新缺口证据 ──► 回灌 S1/S3
                     └──► 失败站位 ──► 回灌 S3 的去重集合
```

### 5.2 各步骤

**S1 缺口证据与分数构建。** 将设计建筑信息模型的三角面按法向一致性切分为表面
分块；将已采集点云中的点关联至表面分块；逐分块统计观测量并归一为缺口证据；加权
融合得到缺口分数 G_gap，再结合所属构件的工程重要度得到任务分数 G_task。每个表面
分块携带形心、单位法向、面积、G_gap 与 G_task。

**S2 移动平台可通行空间构建。** 在场地平面上建立分辨率为 res 的栅格。对设计模型
中的每个构件：若其顶面高度不大于预设跨越高度 z_step，则视为可站立的地面，不标记
为障碍；若其底面离地净空大于移动平台高度 h_robot，则视为可从下穿行，不标记为
障碍；否则将其平面占位所覆盖的栅格标记为障碍。对带电构件，按其对地安全距离追加
标记为禁入。对全部已标记栅格，按移动平台半径 r_robot 作膨胀，膨胀后仍未被标记的
栅格构成自由空间 F。

**S3 目标分块筛选与候选站位生成。**
(a) 将 S1 的表面分块按其所属构件分组；每一构件按 G_task 与面积之积降序取不超过
预设条数的分块；所取分块合并为目标分块集合 L_tgt，其容量随设计模型中构件的数量
缩放。
(b) 在每个目标分块的法向侧按预设距离档取点，并叠加在 F 上按预设间距取的栅格
节点，构成候选位置初集。
(c) 将初集中的每个点投影至 F 内距其最近的自由栅格；投影距离超出预设上限者剔除；
与已执行站位集合 E_ok 及失败站位集合 E_bad 中任一站位的平面距离小于预设去重半径
r_dup 者剔除。
(d) 自当前位姿 v₀ 在 F 上作一次单源最短路求解，得到 v₀ 至 F 内全部自由栅格的
路径长度；据此为每个候选赋路径长度 ℓ(v)；ℓ(v) 为无穷者剔除。

**S4 候选站位评估。** 对每个候选站位 v 与每个表面分块 j：自 v 向 j 的表面采样点
投射射线，在**规划用遮挡模型 M_plan** 上取首次命中；命中 j 自身的采样点占该分块
采样点总数的比例即可见率 Vis(j,v)；结合正视性 f(j,v) 与量程—点密度质量项
g(j,v)，得到覆盖成功概率 q′(j,v)=f·g·Vis；由 q′ 与 G_task、面积合成候选价值
V′(v)。M_plan 的初始内容为设计模型的三角面集合 T。

**S5 站位集合选择及路线生成。** 以 Q=[q′(j,v)] 构造关于站位集合的单调子模覆盖
函数；为每个候选赋等效成本，其值为该候选的路径长度与单站作业时间折算的等效长度
之和；在剩余预算 B 内按边际收益与等效成本之比作贪心选择，得到站位集合 S；对 S
求解开环路线 R。

**S6 确定本轮执行站位并获取新增观测。** 取 S 中满足 ℓ(v) ≤ B 的子集 S_afford；
按预设执行规则自 S_afford 中确定本轮执行站位 v_k。**当 S_afford 为空时，自 S3 的
全部候选中取满足 ℓ(v) ≤ B 者，按 V′ 取最大的一个作为 v_k；若该集合亦为空，则
终止流程并记录终止原因。** 移动至 v_k 并重新采集，得到新增点云 P_k。

**S7a 在线发现模型外遮挡物。** 对 P_k 中每个回波点 x，计算

    d(x, T) = min_{t ∈ T} d(x, t)

其中 T 为设计模型的三角面集合，d(x, t) 为点 x 到单个三角面 t 的最近欧氏距离。
保留同时满足 d(x, T) > ε 且 x 的高度大于预设地面高度阈值 z₀ 的回波点，构成模型外
表面点集 P_out。对 P_out 按预设边长 a 作体素化，取所得占据体素的集合 U_k。

**S7b 新增观测的配准可用性判定（可选）。** 统计 v_k 所观测到的采样点中同时被
E_ok 中站位所观测到者的比例，记为实际重叠比例 O_real，其点数记为 K；对该重叠区域
的采样点及其法向构造点到面信息矩阵，取其条件数的单调变换作为几何退化度 Degen。
若 O_real 低于预设下限 O_min，则判定 P_k 不可用于更新全局数据。

**S8 更新与重新规划。**
(a) 令 M_plan ← M_plan ∪ U_k。**U_k 中的体素不建立与任何表面分块的归属关系，
即不构成新的待扫描目标；待扫描目标集合始终由设计建筑信息模型的构件清单确定。**
(b) 若 P_k 判定为可用，则以 P_k 重算点—分块关联与全部缺口证据，得到更新后的
G_gap 与 G_task，并将 v_k 加入 E_ok；若判定为不可用，则不以 P_k 更新缺口证据，
并将 v_k 加入 E_bad。
(c) 自 B 中扣减本轮消耗的路径长度与作业时间等效量。
(d) 若 B 仍允许且仍存在缺口分块，则以更新后的 M_plan 与缺口证据返回 S3。

## 6. 有益效果

**本节只记载实验实际支持的效果。** 所有实验均在合成场站场景与降级射线仿真器上
完成（角步长 0.4°，真实地面激光扫描仪为 0.02–0.08°；无波形与大气模型），
另在一栋真实建筑的设计模型与实测点云上验证了流程可执行性。**本方法尚未在真实
工业场站的实测数据上完成效果验证。**

### 6.1 在线遮挡发现降低可见性预测误差

在设置了 6 个模型外遮挡物的场景中，以 3 个初始站位建立发现集合后，于 7 个网格
视点、约 500 个表面分块上比对预测可见率与实际可见率：

| 种子 | 仅用设计模型 |  | 并入发现体素 |  | 平均绝对误差降低 |
|---|---|---|---|---|---|
| | 高估条目 | 平均绝对误差 | 高估条目 | 平均绝对误差 | |
| 0 | 502 | 0.1063 | 10 | 0.0123 | 8.7 倍 |
| 1 | 381 | 0.0730 | 0 | 0.0267 | 2.7 倍 |
| 2 | 407 | 0.0795 | 19 | 0.0196 | 4.1 倍 |

设计模型与现场一致时不产生任何发现体素，即该机制在无失配时不引入扰动。

**须一并记载的代价**：体素化带来的外扩使误差由单向高估变为双向，上述三个种子的
低估条目分别由 0 增至 132、242、188 条；地面高度阈值使遮挡物底部留有一条缝隙，
在规划用遮挡模型中可以穿视而现实中不能。

**本效果为"可见性预测误差降低"。** 在设置模型外遮挡物的对照实验中，该机制对最终
缺口恢复率的影响未达统计显著（构件等权恢复率差值 +0.023，配对置换检验 p=0.50，
15 对配对样本）。**因此不主张本机制提高最终扫描恢复率。**

### 6.2 完整方案相对基线的缺口恢复率

在 3 类场景 × 8 个随机种子 × 6 种方法共 144 次运行、24 组配对比较中：

| 方法 | 缺口加权恢复率 | 构件等权恢复率 | 关键构件召回 | 路径(m) |
|---|---|---|---|---|
| 随机站位 | 0.470 | 0.620 | 0.621 | 138 |
| 最大离散度启发式（不使用任何缺口证据） | 0.924 | 0.905 | 0.885 | 244 |
| 离线设计模型覆盖规划 | 0.896 | 0.873 | 0.871 | 230 |
| 在先方案的单视点选取 | 0.779 | 0.322 | 0.311 | 132 |
| 仅遮挡与量程感知 | 0.927 | 0.906 | 0.920 | 249 |
| **本方案** | **0.970** | **0.929** | **0.931** | **156** |

配对置换检验并经 Holm 多重比较校正后，本方案在缺口加权恢复率上相对上述全部五条
基线的优势均达统计显著（校正后 p 分别为 0.0010、0.0060、0.0088、0.0010、0.0010）。
在构件等权恢复率上，相对随机站位与在先方案显著（均为 0.0010），相对其余三条基线
未达显著（均为 0.1299）。

**"构件"在本文中统一指设计建筑信息模型中的建模构件对象，不是物理设备台数**——
一台主变压器在模型中对应箱体与数片散热片共若干个建模构件。

### 6.3 跨场景规模与密度的稳定性

在 3 种场地规模 × 3 种设备密度共 9 类场景、每类 3 个随机种子共 108 次运行中，
预算按每固定数量的建模构件给一站分配：

| 方法 | 9 类场景均值 | 变异系数 | 最差场景 |
|---|---|---|---|
| **本方案** | **0.974** | **0.020** | L/low 0.935 |
| 仅遮挡与量程感知 | 0.966 | 0.022 | L/low 0.933 |
| 离线设计模型覆盖规划 | 0.964 | 0.030 | S/low 0.892 |
| 最大离散度启发式 | 0.904 | 0.071 | M/low 0.807 |

本方案在 9 类场景上的平均缺口加权恢复率最高，同时变异系数最低。相对最大离散度
启发式，在中等规模场景上差值 +0.116、在大规模场景上 +0.082，均达统计显著；在小
规模场景上差值 +0.010，未达显著。

### 6.4 预算内可达回退避免零结果输出

在同一场景上改变路径预算：预算 400 m、60 m、25 m 分别执行 6 站、3 站、1 站，缺口
加权恢复率分别为 0.988、0.817、0.638，随预算单调下降。未设该回退时，25 m 预算下
执行 0 站、恢复率为 0.000，而此时预算内可达的候选站位有 202 个。

### 6.5 目标分块按构件分组保证候选覆盖

按固定条数截断目标分块集合时，即便在最小规模场景中，隔离开关的 144 个表面分块、
电流电压互感器的 72 个、避雷器的 72 个、绝缘子的 20 个均未获得任何为其生成的候选
站位；大规模场景中相应数字为 576、288、288、40。按构件分组并使集合容量随构件
数量缩放后，全部构件与全部构件类别的候选覆盖率由 0 提升至 100%。

### 6.6 配准失败站位进入去重集合避免重复选取

在一次配准失败发生的场景中，未将失败站位加入去重集合时，六轮全部停留在同一位置、
缺口加权恢复率为 0.000；加入后访问 6 个不同位置，在该站失败的情况下恢复率
达 0.876。

### 6.7 单源最短路距离场降低候选评估开销

以自当前位姿的一次单源最短路求解替代逐候选的最短路搜索，所得路径长度与逐候选
搜索逐点一致（抽样比对最大差 0.000000），大规模场景中候选生成耗时由约 53 秒降至
3.5 秒。

### 6.8 真实建筑数据上的可执行性

在一栋真实建筑的设计模型（604187 个顶点、1197750 个三角面、256 个建模构件、切分
为 7019 个表面分块，占地 18.2 m × 24.5 m，表面积 3836.5 m²）与其 584701977 个
实测点上，本方法可完整执行并输出补充扫描站位与路线。

**该实施例仅用于说明本方法能够消费真实设计模型与真实实测点云、流程在真实建筑
数据上可执行。由于仅有一栋建筑、一个主要随机种子，不据此主张本方法在真实建筑
上普遍优于其他方法，亦不据此主张泛化能力。**

## 8. 具体实施方式

### 8.1 实施环境

传感器参数组取：最小量程 0.5 m，最优距离 10 m，最大量程 60 m，角步长 0.4°，
测距噪声标准差 0.005 m。移动平台取：半径 0.6 m（户外轮式平台）或 0.35 m（室内
三脚架），高度 1.8 m，行进速度 0.5 m/s，单站架设与扫描耗时 180 s。

### 8.2 S1 的实施方式

表面分块的切分采用法向一致性区域生长，法向夹角阈值取 20°，分块面积下限取
0.01 m²。表面采样点数按 M = clip(ceil(A/a₀), M_min, M_max) 确定，其中 A 为分块
面积，实施值 a₀ = 0.25 m²/点、M_min = 16、M_max = 1024；面内采样位置由 Halton
序列驱动，序列种子由分块标识的稳定摘要给出，使同一分块的任意两次评估得到相同的
采样点。

**M_min 不取更小值的原因**：关键构件的分块面积中位数约 0.25 m²，若 M_min 取 4，
则此类分块的覆盖率只能取 {0, 0.25, 0.5, 0.75, 1} 五个值，而覆盖判据为"当前覆盖
不低于参考覆盖的一半"，分辨率不足。取 16 使覆盖率分辨率细化至 1/16，大面积分块的
物理采样密度不受影响，仍为 4 点/m²。

### 8.3 S2 的实施方式

栅格分辨率 res = 0.25 m；跨越高度 z_step = 0.20 m；带电构件的对地安全距离按电压
等级取，110 kV 实施值 1.5 m。

障碍栅格的标记有两种实施方式：
- **方式一（按构件平面包围盒）**：以构件的轴对齐平面包围盒覆盖的栅格为障碍。
  适用于形状接近长方体的场站设备。
- **方式二（按三角面投影）**：取构件中竖向跨度与 [z_step, h_robot] 相交的三角面，
  将其平面投影覆盖的栅格标记为障碍。适用于形状为 L 形、带洞口或细长的构件。

在一栋真实建筑上比较：方式一得到的自由空间中最大连通区域仅占自由空间的 28%，
方式二为 79%。原因是该建筑中存在 L 形墙体与带门洞的墙体，其平面包围盒会将洞口
连同墙体一并覆盖。

对于建筑类场景，门、窗与洞口构件在通行意义上是通路而非障碍，可列入不标记为障碍
的类别；该取舍属于按场景类型的配置，不改变 S2 的其余步骤。

### 8.4 S3 的实施方式

每构件取不超过 2 个表面分块；目标分块集合容量取 min(max(2×构件数, 60), 400)。
距离档取最优距离的 0.4、0.8、1.4 倍（最优距离 10 m 时为 4 m、8 m、14 m）；栅格
节点候选的间距取 10 m；去重半径 r_dup 取 3 m；投影上限取 2 m。

**上述数值为户外场站的实施值。** 在一栋真实建筑上，房间尺度只有数米，距离档
需改取 1.5 m、3 m、5 m，栅格节点间距改取 3 m，去重半径改取 1 m；否则候选点全部
落入墙体内部而投影失败。这说明上述数值是随场景尺度配置的参数，不是固定值。

单源最短路求解采用八邻域 Dijkstra，对角移动的代价取 √2，且要求对角移动的两个
正交邻格均为自由栅格（防止贴角穿越障碍）。

### 8.5 S4 的实施方式

首次命中查询基于包围体层次结构加速。正视性取分块单位法向与"自分块形心指向站位"
单位向量点积的正部；量程—点密度质量项由该站位在该分块上的期望点密度与所需点密度
之比截断到 [0,1] 得到。

**可选实施方式（不进入权利要求）**：候选价值中可追加一项配准支持项，其值由预期
重叠率与重叠区域几何退化度合成，用于在信息增益相近的候选之间倾向选择配准条件更
好的站位。在本申请的实验中，将该项权重置零后闭环结果逐位不变，因此**本说明书
仅记载其机理，不主张其带来恢复率、路径长度或决策质量方面的增益**。

### 8.6 S5 的实施方式

集合函数取 F(S) = Σ_j G_task_j · A_j · (1 − Π_{v∈S}(1 − q′(j,v)))，其中 A_j 为
分块面积。该函数单调且子模，采用惰性贪心按边际收益与等效成本之比选取，并与"预算
内单点最优"取大。等效成本取 ℓ(v) + t_scan · v_move，其中 t_scan 为单站作业时间、
v_move 为行进速度，实施值 180 s 与 0.5 m/s，即等效长度 90 m。开环路线由旅行商
问题求解器给出，求解时限 3 s。

### 8.7 S6 的实施方式

预设执行规则的三种具体实现：
- **规则 A（优选）**：执行 S5 所得路线中的首个站位。
- **规则 B**：执行在惰性贪心选取过程中最先被选中的站位。
- **规则 C**：执行使单步目标函数增量最大的站位；该目标函数按步内极值归一，即
  信息项除以本轮各候选信息增量的最大值、路径项除以本轮各候选路径长度的最大值。

三种规则在合成场景上的对照（3 类场景 × 5 个种子共 45 次运行）：规则 A 的缺口
加权恢复率 0.977、关键构件召回 0.956、路径 153 m；规则 C 相应为 0.967、0.924、
230 m；单位路径增益的差异经 Holm 校正后 p = 0.0006。在真实建筑上，三种规则的
缺口加权恢复率分别为 0.959、0.958、0.958。故以规则 A 为优选实施方式，同时保留
B 与 C 作为可选实施方式。

### 8.8 S7a 的实施方式

距离阈值 ε = 0.25 m；地面高度阈值 z₀ = 0.35 m；体素边长 a = 0.40 m，取与移动
平台半径同量级。参与判定的点数上限取 200000，超出时按固定种子的随机数生成器
均匀抽样，因体素化本身已高度冗余，抽样不改变占据体素集合的主体。

最近距离 d(x, T) 由无符号距离场查询得到。**本步骤只需要该最小距离的数值，不需要
确定由哪个三角面取得该最小值；若多个三角面同时取得该最小值，不影响 d(x,T) > ε
的判定结果。** 仅当某个可选实施方式还要求把该回波点唯一归属至某个构件或三角面时，
才需要引入确定性归属规则。

### 8.9 S7b 的实施方式

实际重叠比例 O_real 取 v_k 所见采样点中同时被此前站位所见者的数量与 v_k 所见
采样点总数之比。几何退化度 Degen = 1 − λ_min/λ_max，其中 λ_min、λ_max 为将
点到面信息矩阵的平移块与旋转块分别按迹归一后所得矩阵的最小与最大特征值。
O_min 实施值 0.30。

可选地，可由重叠点数 K 与 Degen 给出位姿误差的量级估计
σ ≈ σ_floor + σ_meas / √K · √(1/(1 − Degen))，并与预设容差比较；该式为受
Cramér–Rao 下界启发的量级估计，非严格的 Cramér–Rao 下界。

### 8.10 S8 的实施方式

规划用遮挡模型的更新采用：将占据体素展开为独立立方体三角网，与设计模型三角面
合并后重建包围体层次结构；合并后的三角面中，属于发现体素者其分块归属标识置为
"无归属"，从而在 S4 的首次命中判定中只作为遮挡体、不作为命中目标。仅在本轮确有
新增占据体素时才重建，无新增时沿用上一轮的结构。

## 10. 边界情况与异常处理

按指导 §3，只列真实数据中可能发生、且会影响结果确定性或后续处理的情况。

| 情况 | 处理方式 |
|---|---|
| S3 候选集合为空 | 终止流程并记录终止原因为"无候选" |
| S3 中某候选投影失败（周边无自由栅格） | 剔除该候选，不影响其余候选 |
| S3 中某候选不可达（ℓ(v)=+∞） | 剔除该候选 |
| S5 所选站位集合中无预算内可达者 | 按 S6 的回退分支处理，不终止 |
| S6 回退时预算内亦无可达候选 | 终止流程并记录终止原因为"无可达候选" |
| S7a 中 P_out 为空（未发现模型外遮挡物） | U_k 为空集，M_plan 不变，不重建包围体层次结构，其余步骤照常 |
| S7a 中 d(x,T) 有多个三角面同时取最小 | 不影响阈值判定，见 8.8 |
| S7b 中 K < 3（重叠点过少） | 判定为不可用 |
| S7b 中 Degen 趋近 1（重叠区完全退化） | 位姿误差量级估计中对 Degen 作上限截断，避免除零 |
| 某分块采样点数不足 6，其信息矩阵不可构造 | 该分块不参与退化度计算 |
| 某分块面积趋近 0 | 由 S1 的面积下限剔除 |
| 某分块的所有采样点均不可见 | q′ 为 0，该分块对该候选无贡献；若候选对全部分块的 q′ 均为 0，剔除该候选 |
| 分母为 0（如覆盖率归一时分块无采样点） | 该分块覆盖率取 0 |
| 多个候选价值完全相同 | 按候选生成顺序取先者；候选生成顺序由目标分块顺序与距离档顺序确定，而目标分块按标识排序，因此该顺序不依赖存储顺序 |
| 缺口分块数为 0 | S8(d) 的循环条件不满足，正常结束 |
| 预算在首轮即为 0 或负 | 不执行任何站位，记录终止原因为"预算耗尽" |

**关于确定性与可复现**（按指导 §4）：本方法中涉及随机性的环节仅有两处——表面
采样点的 Halton 序列与 S7a 的点数抽样，二者的种子均由稳定摘要或固定值给出，
不依赖进程内的哈希随机化。候选生成、集合选择与路线求解均为确定性过程。

## 13. 实施例二：真实建筑

设计模型为某实验楼的 IFC 模型，含 256 个建模构件（家具 66、墙体 61、洞口 54、
窗 44、柱 10、面层 7、门 6、板 5、楼梯 2、其他 1），604187 个顶点、1197750 个
三角面，切分为 7019 个表面分块，占地 18.2 m × 24.5 m，表面积 3836.5 m²。实测
点云为 584701977 个点，按 5 cm 阈值关联至构件，匹配 12835294 个点。

**该实施例的实施条件与合成场景不同之处**（均属按场景尺度的参数配置，不改变
S1–S8 的步骤）：平台半径取 0.35 m；障碍栅格采用按三角面投影的方式二；门、窗与

**最后一项的原因**：真实建筑的自由空间被墙体分隔为多个互不连通的区域，若在全部
自由空间上取最远点，初始站位会落入彼此不可达的房间，此后任一站位至其余位置的

在上述配置下，本方法完整执行 28 站并输出站位与路线，缺口加权恢复率 0.959、构件
等权恢复率 0.981、关键构件召回 0.956。

**本实施例的限制**：该数据集仅提供一份融合后的点云，不含逐站位姿，因此补充扫描
站位的重新采集由射线仿真器在真实设计模型上完成——几何与缺口来自真实数据，重新
采集为仿真。该实施例用于说明本方法能够消费真实设计模型与真实实测点云、流程可
执行，不据此主张本方法在真实建筑上普遍优于其他方法。
