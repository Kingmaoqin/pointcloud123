# 阶段 4：权利要求逻辑骨架

## 4.1 逐步骤四要素表

### S1 缺口证据与分数构建

- **输入对象**：设计建筑信息模型的三角面集合 T 及其构件划分；已采集点云 P₀。
- **执行动作**：按法向一致性将 T 切分为表面分块；将 P₀ 中的点关联至分块；逐分块
  统计观测量并归一为缺口证据；加权融合为缺口分数，再按构件的工程重要度得到任务
  分数。
- **判断/计算依据**：沿用在先方案的分块切分与证据融合规则。
- **输出**：分块集合 L，每个分块携带形心、单位法向、面积、缺口分数 G_gap、任务
  分数 G_task。
- **被哪一步使用**：S3 用 G_gap、G_task 与面积筛目标；S4 用形心、法向、面积、
  G_task 算收益。

### S2 移动平台可通行空间构建

- **输入对象**：设计模型构件的平面占位、构件底面离地净空、带电构件的对地安全
  距离；移动平台的半径与高度。
- **执行动作**：在场地平面上建立栅格；将底面净空小于平台高度、且顶面高于跨越
  高度的构件所占栅格标记为障碍；对带电构件按其对地安全距离追加标记；对已标记
  栅格按平台半径作膨胀。
- **判断/计算依据**：顶面高度是否低于跨越高度（低于则视为可站立地面，不标记）；
  净空是否大于平台高度（大于则可从下穿行，不标记）。
- **输出**：自由空间栅格 F（布尔）。
- **被哪一步使用**：S3 把候选投影到 F 内并剔除 F 外者；S3 在 F 上求路径长度。

### S3 目标分块筛选与候选站位生成

- **输入对象**：S1 的分块集合 L；S2 的自由空间 F；当前位姿 v₀；已执行站位集合
  E_ok；失败站位集合 E_bad（S7b 产生，首轮为空）。
- **执行动作**：
  (a) 目标筛选——将 L 按所属构件分组，每一构件按任务分数与面积之积取不超过预设
      条数的分块，构成目标分块集 L_tgt，其容量随模型中构件数量缩放；
  (b) 候选生成——在每个目标分块的法向侧按预设距离档取点，并叠加 F 上按预设间距
      取的栅格节点，构成候选位置初集；
  (c) 投影与剔除——将初集中的点投影至 F 内最近自由栅格，投影失败者剔除；与
      E_ok ∪ E_bad 中任一站位距离小于预设去重半径者剔除；
  (d) 路径长度——自 v₀ 作一次单源最短路求解，得到 v₀ 至 F 内全部自由栅格的路径
      长度，据此为每个候选赋路径长度；路径长度为无穷者剔除。
- **判断/计算依据**：每构件条数上限；集合容量随构件数缩放；去重半径；可达性。
- **输出**：候选站位集合 V，每个候选携带位置与自 v₀ 的路径长度 ℓ(v)。
- **被哪一步使用**：S4 逐候选评估；S5 用 ℓ(v) 构成等效成本。

### S4 基于规划用遮挡模型的候选站位评估

- **输入对象**：S3 的候选集合 V；S1 的分块集合 L；**规划用遮挡模型 M_plan**
  （首轮取设计模型三角面集合 T；其后取 S8 更新后的版本）。
- **执行动作**：对每个候选 v 与每个分块 j，自 v 向 j 的表面采样点投射射线，在
  M_plan 上取首次命中，命中自身分块的采样点比例为可见率；结合正视性与量程—点
  密度质量项，得到覆盖成功概率 q'(j,v)；由 q' 与任务分数、面积合成候选价值 V'(v)。
- **判断/计算依据**：首次命中是否为该分块自身；距离是否落在传感器量程内；正视性
  是否为正。
- **输出**：覆盖成功概率矩阵 Q=[q'(j,v)]；候选价值向量 V'。
- **被哪一步使用**：S5 用 Q 构造集合函数、用 V' 作回退择优的依据。

### S5 预算约束下的站位集合选择及路线生成

- **输入对象**：S4 的 Q；S1 的任务分数与面积；S3 的路径长度 ℓ(v)；剩余预算 B。
- **执行动作**：以 Q 构造关于站位集合的单调子模覆盖函数；为每个候选赋等效成本
  （路径长度与单站作业时间的等效长度之和）；在预算内按"边际收益与等效成本之比"
  作贪心选择，得到站位集合 S；对 S 求开环路线 R。
- **判断/计算依据**：集合函数的边际增益；等效成本；累计成本不超过预算。
- **输出**：站位集合 S 与路线 R。
- **被哪一步使用**：S6 从 S（及 R）中确定本轮执行站位。

### S6 确定本轮执行站位并获取新增观测

- **输入对象**：S5 的 S 与 R；S3 的 ℓ(v)；剩余预算 B；S4 的 V'。
- **执行动作**：
  (a) 可达性过滤——取 S 中满足 ℓ(v) ≤ B 的子集 S_afford；
  (b) **回退**——若 S_afford 为空，则在 S3 的全部候选中取满足 ℓ(v) ≤ B 者，按 V'
      取最大的一个作为本轮执行站位；若该集合亦为空，则终止并记录终止原因；
  (c) 执行规则——若 S_afford 非空，按预设执行规则自 S_afford 中确定本轮执行站位；
  (d) 移动至该站位并重新采集，得到新增点云 P_k。
- **判断/计算依据**：ℓ(v) 与 B 的比较；预设执行规则。
- **输出**：本轮执行站位 v_k；新增点云 P_k；本轮消耗的路径长度。
- **被哪一步使用**：S7a 与 S7b 处理 P_k；S8 扣减预算。

### S7a 在线发现模型外遮挡物

- **输入对象**：S6 的新增点云 P_k；设计模型三角面集合 T。
- **执行动作**：对 P_k 中每个回波点 x，计算 x 至 T 中全部三角面的最近欧氏距离
  d(x,T)=min_{t∈T} d(x,t)；保留同时满足 d(x,T) > ε 且 x 的高度大于预设地面高度
  阈值 z₀ 的点，构成模型外点集 P_out；对 P_out 按预设边长 a 体素化，取所得占据
  体素的集合 U_k。
- **判断/计算依据**：d(x,T) 与 ε 的比较；x 的高度与 z₀ 的比较。
  **本步骤只需要最小距离的数值，不需要确定由哪个三角面取得该最小值；若多个三角面
  同时取得该最小值，不影响 d(x,T) > ε 的判定结果。**
- **输出**：本轮发现的模型外遮挡体素集合 U_k（可能为空集）。
- **被哪一步使用**：S8 将 U_k 并入规划用遮挡模型。

### S7b 新增观测的配准可用性判定（可选步骤）

- **输入对象**：S6 的 v_k 及其可见掩码；此前各已执行站位的累计可见掩码。
- **执行动作**：统计 v_k 所见采样点中同时被此前站位所见者的比例（实际重叠比例）
  与其点数；对该重叠区域的采样点及其法向构造点到面信息矩阵，取其条件数的单调
  变换作为几何退化度；据预设条件判定 P_k 是否可用于更新全局数据。
- **判断/计算依据**：实际重叠比例是否低于预设下限；（可选）由重叠点数与几何退化
  度给出的位姿误差量级是否超出预设容差。
- **输出**：可用性标志；若不可用，则 v_k 进入失败站位集合 E_bad。
- **被哪一步使用**：S8 决定是否以 P_k 更新缺口证据；E_bad 回灌 S3 的去重集。

### S8 更新与重新规划

- **输入对象**：U_k；可用性标志；P_k；当前 M_plan、缺口证据、E_ok、E_bad、B。
- **执行动作**：
  (a) M_plan ← M_plan ∪ U_k，其中 U_k 中的体素**不建立与任何分块的归属关系**，
      即不构成新的待扫描目标；
  (b) 若 P_k 可用，则以 P_k 重算点—分块关联与全部缺口证据，得到更新后的
      G_gap、G_task，并将 v_k 加入 E_ok；若不可用，则不以 P_k 更新证据，并将
      v_k 加入 E_bad；
  (c) B ← B 减去本轮消耗；
  (d) 若 B 仍允许且仍存在缺口分块，返回 S3。
- **输出**：更新后的 M_plan、缺口证据、E_ok、E_bad、B。
- **被哪一步使用**：S3（去重集、目标筛选）、S4（M_plan）。

## 4.2 核心闭环与断点检查

```
设计模型 T + 已采集点云 P₀
        │
        ▼  S1
   缺口证据与分数 (G_gap, G_task)
        │                              ┌──────────────┐
        ▼  S2 → S3                     │              │
   可通行候选集合 V + 路径长度 ℓ(v)      │              │
        │                              │              │
        ▼  S4（读 M_plan）              │              │
   覆盖成功概率 Q + 候选价值 V'          │              │
        │                              │              │
        ▼  S5                          │              │
   站位集合 S + 路线 R                  │              │
        │                              │              │
        ▼  S6（含预算内可达回退）        │              │
   本轮执行站位 v_k + 新增观测 P_k       │              │
        │                              │              │
        ├──► S7a ──► 模型外体素 U_k ────┤              │
        │                              ▼              │
        │                        S8(a) M_plan 更新 ────┘（回灌 S4）
        │
        └──► S7b ──► 可用性标志 ──► S8(b) 缺口证据更新（回灌 S1/S3）
                            └──► 失败站位 E_bad ──► S3 去重集
```

**断点检查**（逐对相邻步骤核对"前一步产生了什么，使后一步能够执行"）：

| 相邻步骤 | 前一步的输出 | 后一步实际消费的对象 | 是否一致 |
|---|---|---|---|
| S1→S3 | 分块 + G_gap/G_task/面积 | 同上，用于分组取样 | ✅ |
| S2→S3 | 自由空间栅格 F | 投影目标、栅格节点候选、可达性 | ✅ |
| S3→S4 | 候选集合 V | 逐候选射线求交 | ✅ |
| S3→S5 | 路径长度 ℓ(v) | 等效成本 | ✅ |
| S4→S5 | Q | 子模集合函数 | ✅ |
| S4→S6 | V' | 回退时的择优依据 | ✅ |
| S5→S6 | S、R | 可达性过滤与执行规则 | ✅ |
| S6→S7a | 新增点云 P_k | 最近距离计算 | ✅ |
| S6→S7b | v_k 的可见掩码 | 重叠比例与退化度 | ✅ |
| S7a→S8 | 体素集合 U_k | 并入 M_plan | ✅ |
| S7b→S8 | 可用性标志、E_bad | 证据更新开关、去重集 | ✅ |
| S8→S4 | 更新后的 M_plan | 下一轮射线求交 | ✅ |
| S8→S3 | 更新后的证据、E_ok、E_bad、B | 目标筛选、去重、预算 | ✅ |

**结论**：不存在"前一步输出 A、下一步突然使用 B"的断点。

**闭环必要性**：S7a 的输出唯一去向是 S8(a)，而 S8(a) 的唯一消费者是下一轮的 S4。
若不重复执行 S3–S7，S7a 不产生任何作用。因此闭环是本方案的必要组成，而非进一步
优化。

# 阶段 5：两套权利要求结构

**两套结构不可混用。** 选定后全篇按同一套推进。

## 5.A 宽保护方案

### 权利要求 1（独立权）

一种补充扫描规划方法，其特征在于，包括：

**S1** 依据设计建筑信息模型与已采集点云，确定所述设计建筑信息模型的表面分块的
缺口证据与任务分数；

**S2** 依据所述设计建筑信息模型中构件的平面占位与高度信息，以及移动平台的尺寸，
构建所述移动平台的可通行空间；

**S3** 依据所述缺口证据在所述可通行空间内生成多个候选补充扫描站位，并确定当前
位姿至各候选补充扫描站位的路径长度；

**S4** 依据规划用遮挡模型，计算各候选补充扫描站位对各表面分块的可见性，并据以
确定各候选补充扫描站位的价值；所述规划用遮挡模型的初始内容为所述设计建筑信息
模型的表面；

**S5** 在包含路径长度与作业时间的预算约束下，自所述候选补充扫描站位中选定站位
集合并生成路线；

**S6** 按照预设执行规则，自所述站位集合中确定本轮执行的站位，移动至该站位并获取
新增点云；

**S7** 计算所述新增点云中各回波点至所述设计建筑信息模型全部表面的最近距离，将该
最近距离大于预设距离阈值、且高度大于预设地面高度阈值的回波点判定为模型外表面
点，并对判定所得的模型外表面点集合作体素化；

**S8** 将所述体素化所得的体素并入所述规划用遮挡模型，且不为所述体素建立与任何

## 5.B 稳创造性方案

在 5.A 权 1 的基础上，将下列特征并入独立权：

- 将 5.A 权 2 的**预算内可达回退**并入 S6；
- 将 5.A 权 3 的**执行路线首站**并入 S6 的执行规则；
- 在 S8 中明确"以更新后的规划用遮挡模型重新计算后续候选补充扫描站位的可见性"
  （5.A 中此关系隐含于"重新执行 S3 至 S7"，此处显式化）。

### 每一项并入的代价与收益

| 并入的特征 | 为什么创造性更稳 | 因此牺牲了什么保护范围 |
|---|---|---|
| 预算内可达回退 | 它与"整条路线的预算"和"每轮只执行一站"这一对矛盾直接绑定，是本方案特有的技术关系；单独看不易被现有技术公开 | 不作回退、预算耗尽即终止的实施方式落到保护范围之外 |
| 执行路线首站 | 与"生成路线"形成完整因果（生成路线是为了确定执行顺序），链条更闭合 | **代价最大**。放弃对执行规则 B、C 的覆盖，而实测在真实建筑上三种规则结果几乎相同（0.959/0.958/0.958），竞品改用 B 或 C 即可绕开 |
| 显式化"用更新后的遮挡模型重算可见性" | 把闭环的回灌关系写死，杜绝"发现了但不用"的规避解释 | 几乎不牺牲——该关系本就是 N4，属必要特征 |

### 建议

**优先采用 5.A**，理由：执行规则 A/B/C 是真正的替代路径（实测真实建筑上三者
等效），把 A 写入独立权会以很小的创造性增益换取明显的规避空间。

**⚠️ 这是权项布局问题，不只是文字修改问题。** 最终应结合代理人的检索结果决定：
若检索发现 N1–N5 的组合已被部分公开，则 5.B 是必要的退守方案。
