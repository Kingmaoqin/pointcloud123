## 二、两个疑问的结论

**疑问 1（公式(9)中 x、y 的数学形式与距离计算）** —— 我方原稿确实缺漏，已补齐：给出 x 的坐标形式、y 的重心坐标形式、欧氏范数展开，以及点到三角面最近距离的**闭式求法**（投影判定 + 边/顶点回退）。该闭式算法与本项目实际实现比对，400 个随机点上**最大偏差 1.46×10⁻⁷ m**，在单精度浮点精度内一致。

**疑问 2（是否存在距离相等、应归属谁）** —— **存在，且不是可以忽略的个例。**

- 在**凸棱**（两表面夹角小于 180°，如柱棱、墙角、梁棱）外侧，以该棱为脊、张角等于 180° 减去两面夹角的**三维楔形区域**内，每一点的最近表面点都落在棱上，因而到棱两侧表面的距离**处处严格相等**——这是**正体积区域**，不是零测度的个别点（区域内的点可距棱任意远，落在棱上的是它们的最近表面点）；
- 更关键的是，双法向约束恰好会把夹角大的两个面分到**不同的表面分块**，该棱通常正是**两个表面分块的公共边界**；在距离阈值 τ_d 限制下，真正参与匹配的等距点位于距该棱 τ_d 以内；
- 我们还测出：现有实现（Open3D）在并列时的取舍**随三角面存储顺序而改变**，底层库未承诺任何规则。

因此必须在方案中**显式规定唯一归属规则**。修订稿 S4 写入的是上位表述"按预设的确定性规则从中择一"；具体规则在我方说明书中完整给出：第一级取最近距离最小者，第二级取"由最近表面点指向该点的方向与该面法向所成夹角的**余弦绝对值**最大者"（取绝对值以不受顶点绕序影响；最近距离为零时该方向无定义，视为并列直接进入下一级），第三级取三角面索引最小者。另给出一个可选的 1/k 均分方案供代理人择定（采用时 S4 须同步改动，详见修订稿末尾提示）。

以上结论均可用 `04_验证材料/verify_s4_association.py` 复现（运行结果已存 `验证运行结果.txt`）。
