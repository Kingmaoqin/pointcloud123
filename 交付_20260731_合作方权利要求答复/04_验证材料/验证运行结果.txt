验证二：凸棱外侧的等距区域（两个表面分块严格等距）
  沿棱外侧45°方向取点（该方向上每一点到两个分块都严格等距）：
    距棱 0.05 m：到分块0 = 0.050000000，到分块1 = 0.050000000，相等=True，实现判给分块0
    距棱 0.10 m：到分块0 = 0.100000000，到分块1 = 0.100000000，相等=True，实现判给分块0
    距棱 0.20 m：到分块0 = 0.200000000，到分块1 = 0.200000000，相等=True，实现判给分块0
    距棱 0.35 m：到分块0 = 0.350000000，到分块1 = 0.350000000，相等=True，实现判给分块0
    距棱 0.50 m：到分块0 = 0.500000000，到分块1 = 0.500000000，相等=True，实现判给分块0
  结论：等距点构成以公共棱为脊的三维楔形区域（正体积），非零测度个例；
        区域内每一点的最近表面点均落在该棱上，而该棱通常即为双法向约束
        所划出的两个表面分块的公共边界。

验证二·补：不相邻表面之间的等距情形
    点[1.  1.  0.5]：各面距离=[0.5, 0.5, 0.5, 0.5]，并列面=[0, 1, 2, 3]，上下表面共享顶点数=0
    点[0.6 0.7 0.5]：各面距离=[0.5, 0.703562, 0.5, 0.703562]，并列面=[0, 2]，上下表面共享顶点数=0
  结论：等距的两个三角面可以不共享任何顶点，故并列面必须在全部三角面中搜索；
        仅搜索相邻面会漏判该情形。

验证三：并列时现有实现的取舍是否稳定
    三角面存储顺序 [0, 1, 2, 3] → 判给原三角面#0（属分块0）
    三角面存储顺序 [2, 3, 0, 1] → 判给原三角面#2（属分块1）
    三角面存储顺序 [3, 2, 1, 0] → 判给原三角面#2（属分块1）
    三角面存储顺序 [1, 0, 3, 2] → 判给原三角面#0（属分块0）
  结论：取舍随三角面存储顺序而变，底层库未承诺任何规则；
        因此必须在技术方案中显式规定唯一归属规则，方案才具备确定性与可复现性。
