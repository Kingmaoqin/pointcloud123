# 实验与证据说明

本表给出说明书"有益效果"一节每一处数字的来源，以及每条主张**可以支持的表述**与
**不得超出的表述边界**。答复审查意见时同样以本表为准。

`实验记录/` 下为各项实验由程序直接输出的原始汇总（含运行环境标识），供核对本表
数值之用。

全部实验在合成场站场景与降级射线仿真器上完成（角步长 0.4°，真实地面激光扫描仪为
0.02–0.08°；无波形与大气模型），另在一栋真实建筑的设计模型与实测点云上验证了
流程可执行性。**本方法尚未在真实工业场站的实测数据上完成效果验证。**

**证据等级**：**[A]** 材料明确支持 ｜ **[B]** 可由材料合理推出 ｜
**[C]** 为完整性建议补充，未实现 ｜ **[D]** 材料不足以确定

## 1. 主张—证据对照

### 1.1 在线遮挡发现降低可见性预测误差

| 项 | 内容 |
|---|---|
| **主张** | 并入发现体素后，候选站位对表面分块的可见性预测的平均绝对误差降低 2.7–8.7 倍 |
| **证据等级** | **[A]** |
| **对应实验** | 遮挡发现可见性误差专项测量 |
| **样本规模** | 3 个随机种子 × 7 个网格视点 × 约 500 个表面分块；设置 6 个模型外遮挡物 |
| **具体数值** | 种子 0：高估 502→10，MAE 0.1063→0.0123（8.7 倍）；种子 1：381→0，0.0730→0.0267（2.7 倍）；种子 2：407→19，0.0795→0.0196（4.1 倍） |
| **可以支持的表述** | "降低可见性预测的平均绝对误差"；"消除绝大部分高估条目"；"设计模型与现场一致时不产生任何发现体素" |
| **明确禁止的表述** | ❌"提高最终扫描覆盖率／缺口恢复率"（见 1.2）；❌"消除预测误差"；❌"完全避免误判" |
| **须一并记载的代价** | 低估条目由 0 分别增至 132、242、188；地面高度阈值使遮挡物底部留缝 |

### 1.4 跨场景规模与密度的稳定性

| 项 | 内容 |

| **证据等级** | **[A]** |

### 1.5 预算内可达回退避免零结果输出

| 项 | 内容 |
|---|---|
| **主张** | 恢复率随预算单调下降，而非在紧预算下崩溃为零 |
| **证据等级** | **[A]** |
| **对应实验** | 预算退化回归测试 |
| **样本规模** | 单场景 4 个预算档 |
| **具体数值** | **可通行路径代价预算**（只计移动路径）400 m / 60 m / 25 m → 6 站（0.988）／3 站（0.817）／1 站（0.638）；未设回退时 25 m 预算下 0 站、恢复率 0.000，而彼时预算内可达候选 202 个 |
| **预算口径核对** | 已核对代码：episode 预算变量只累加各轮的可通行路径代价，判据为"累计路径代价 ≥ 预算"。单站作业耗时折算的等效路径代价（180 s × 0.5 m/s = 90 m）**只**进入站位选择时的候选等效成本比值，不进入 episode 预算。**故 25 m 预算执行 1 站与说明书自洽** |
| **可以支持的表述** | 上述全部 |
| **明确禁止的表述** | ❌ 由单场景推广为"在任意场景下均单调"；❌ 把预算表述为"包含作业时间的总预算"——它只计移动路径 |

### 1.10b 配准失败时新增点云的使用范围（代码事实核对）

| 项 | 内容 |
|---|---|
| **主张** | 判定为不满足预设更新条件时，规划用遮挡模型与缺口证据均保持不变 |
| **证据等级** | **[A]**（代码事实） |
| **结论** | 代码本来就未把失败站的点云用于遮挡模型更新。此前说明书把遮挡模型更新写成无条件，属**文本与代码不符**，已按代码改正 |
| **技术理由** | 判定失败意味着该站数据无法可靠拼入设计模型所在的全局坐标系，其回波点的全局坐标同样不可信，因而无法据以判定"该点离设计模型表面超过 ε"——距离判据本身以两者同处一个坐标系为前提 |
| **例外情形** | 若移动平台具备独立于点云配准的可靠全局定位，则该情形下可照常执行发现步骤。**本申请实施例不属于该情形**，说明书已注明 |
