# 建筑点云缺口补扫视点规划方法、装置、设备及存储介质

## 摘要

本申请公开了建筑点云缺口补扫视点规划方法、装置、设备及存储介质，涉及三维重建技术
领域，包括三角构造、表面划分、点云映射、缺口靶向以及视点定位。本申请首先通过对
IFC 模型的构件表面进行三角划分并按邻接与法向一致性重新拼接为表面分块，将缺口的定位
粒度从构件整体细化到构件的局部表面区域，为后续补扫视点的生成提供明确的空间靶向；
再基于三维点云在各表面分块上的几何覆盖率和点云密度计算缺口分数，以几何覆盖率反映
观测的广度、以点云密度反映观测的强度；最后以缺口分数、分块面积与该候选视点对该
分块的观测质量之积在视锥范围内求和，得到候选补扫视点的价值，据以选取补扫视点，
提高视点规划的空间靶向性。

## 说明书

### 技术领域

本申请涉及三维重建技术领域，特别涉及建筑点云缺口补扫视点规划方法、装置、设备及
存储介质。

### 背景技术

在建筑室内外三维扫描工程中，受现场条件与设备性能制约，单一站位的激光扫描或摄影测量
往往无法完整覆盖目标建筑的全部表面。为获取完整点云数据，通常需采用多站位、多视角的
拼接采集策略。然而，即便在精心规划路径的前提下，由于构件间相互遮挡、扫描入射角过大、
扫描距离超出有效量程、视场范围受限、多站点云配准累积误差以及采集路径存在物理可达性
限制等因素的综合影响，最终生成的点云模型在局部建筑表面上仍可能存在数据覆盖缺失、
点云密度不足等缺陷。

对扫描质量的评判若依赖全局完整性指标（如点云整体覆盖率、点云内平均点间距）或人工
目视检查，仅能反映点云整体的宏观完备程度，难以将数据缺陷定位至具体 IFC 构件的特定
表面区域，后续补充扫描作业因而缺乏明确的空间靶向。

部分现有视点规划方法主要依据几何覆盖、环境未知度或其他全局收益指标选择下一视点，
对于将已有点云的局部质量缺口进一步定位至建筑信息模型中具体构件的表面分块，并据此
计算补扫优先级的处理仍有改进空间。

**有益效果**

本申请通过对 IFC 模型的构件表面进行三角划分，并按共享边邻接关系与两级法向一致性
约束重新拼接为表面分块，将缺口的定位粒度从构件整体细化到构件的局部表面区域，为后续

密度项而计入缺口。

最后以缺口分数、分块面积与观测质量之积在视锥范围内求和作为候选补扫视点的价值，使
所选视点倾向于覆盖缺口程度高、面积大且观测几何较好的表面区域。

#### 关于步骤 S2：表面分块的构造

参见图 2，编号 A1–A6 标识的三角形均为三角面，这六个三角面拼接成某一构件局部的三角
形网络。相邻三角面的相同无向边即相邻三角形的共享边：顶点 E1 与 E2 之间的无向边 V1
为三角面 A1 与 A4 的共享边，顶点 E1 与 E3 之间的无向边 V2 为三角面 A4 与 A5 的共享
边，顶点 E2 与 E3 之间的无向边 V3 为三角面 A4 与 A6 的共享边。

本实施例中，共享边邻接关系仅在同一构件内部建立，不跨构件建立。

三角面的法向是指垂直于三角面所在平面的单位向量，两个法向作点积运算后得到一个数值。
两个法向夹角越大，其点积越小，即两个三角面之间的法向偏移越大。

参见图 3，以三角面 A1 为种子三角面建立一个新的表面分块。与 A1 相邻且尚未归属的三角
面 A2 成为候选三角面；A2 与已纳入该分块且与其相邻的三角面 A1 的法向点积不小于法向
阈值 a（满足第一法向约束），且 A2 与种子三角面 A1 的法向点积不小于 a（满足第二法向
约束），故 A2 被纳入该分块。继而 A3 成为候选三角面：A3 与已纳入的相邻三角面 A2 的
法向点积不小于 a，且 A3 与种子三角面 A1 的法向点积不小于 a，故 A3 亦被纳入。

对于三角面 A4：其与已纳入的相邻三角面的法向点积小于 a，不满足第一法向约束，因而不
被纳入当前表面分块。当前表面分块生长终止，得到由 A1–A3 构成的表面分块（图 3 的阴影
区域）。随后自尚未归属的三角面中重新选择种子三角面（如 A4），重复上述生长过程，
直至该构件内所有三角面均已归属或被剔除。

本实施例中，第一法向约束与第二法向约束采用同一法向阈值 a。第一法向约束比较的是候选
三角面与将其纳入当前分块的那个已纳入相邻三角面，用于控制**局部**法向偏移；第二法向
约束比较的是候选三角面与种子三角面，用于控制沿分块生长方向的**累积**法向偏移。二者
共同限制同一表面分块内各三角面之间的法向偏移程度。

生长完成后，将三角面面积之和小于预设最小分块面积的表面分块剔除，不参与后续处理，
以避免面积过小的碎片分块干扰缺口统计。各表面分块的中心取其所含各三角面形心以三角面
面积为权重的加权平均，法向取其所含各三角面法向以三角面面积为权重的加权平均并归一化。

#### 关于步骤 S3：点云到表面分块的归属

参见图 4，图中实线表示两个三角面的相同无向边，虚线表示距离阈值在两个三角面上分别
对应的边界，实心圆点表示已归属于某一表面分块的采样点，空心圆点表示未归属任何表面
分块的采样点。

计算各采样点与各三角面之间的距离，取最小距离对应的三角面作为该采样点的最近三角面。
当某个采样点与两个以上三角面之间的距离并列最小时（如图 4 中落在实线上的实心圆点），
按下述确定性选择规则逐级适用直至唯一：

第一级，取距离最小者，距离并列的判定包含预设数值容差；本实施例中该容差取 1×10⁻⁶ 米，
其量级依据为：在同一网格与同一批采样点上，由单精度后端与双精度闭式解计算所得的最近
距离最大相差约 6×10⁻⁷ 米，故该容差既能覆盖该量级的浮点差异，又远小于距离阈值。

第二级，取由该三角面上距该采样点最近的表面点指向该采样点的方向与该三角面法向所成
夹角的余弦绝对值最大者；取绝对值使判定不受三角面顶点绕序（即法向朝向）的影响。最近
距离为零时该方向无定义，视为本级并列并进入第三级。

第三级，取该三角面三个顶点坐标按字典序排序后所得序列在字典序上最小者。

第四级，仅在两个三角面几何完全重合时适用，按其所属构件的标识择一。

由于第三级采用三角面自身的几何量而非其在文件中的存储索引，整条规则的结果**不依赖
三角面的存储顺序**，从而使采样点的归属唯一且可复现。

随后将各采样点的最小距离与预设的距离阈值比较，最小距离不大于该阈值的采样点确定为
有效采样点并归属于其最近三角面所属的表面分块；最小距离大于该阈值的采样点不归属于
任何表面分块，从而剔除三维点云中无效的采样点或可能对缺口分数产生扰动的噪点。本实施
例中距离阈值取 0.05 米。

在另一种实施方式中，考虑到逐点计算至各表面分块的归属在大规模点云上开销较高，可先将
各采样点按上述规则归属至相应的**构件**，再按各表面分块的面积占该构件表面总面积的
比例，将该构件所归属的采样点数量分配至其各表面分块，以此得到各表面分块的采样点
数量。该实施方式下，各表面分块的点云密度与几何覆盖率均基于所分配的采样点数量计算。

#### 关于步骤 S4：缺口分数的计算

几何覆盖率 C_i 表示该表面分块上已被观测到的部分占该表面分块的比例。在一种实施方式
中，对表面分块的表面按预设间隔布置若干评估点，统计其中被已有扫描站位实际观测到的
评估点数量占评估点总数的比例，作为该表面分块的几何覆盖率。

点云密度 ρ_i 取归属于该表面分块的有效采样点数量与该表面分块面积之比，即单位面积上
的采样点数量，单位为点每平方米：

    ρ_i = N_i / S_i

式中，N_i 表示归属于第 i 个表面分块的有效采样点数量，S_i 表示第 i 个表面分块的面积。

期望密度 ρ̂_i 与 ρ_i 同量纲，按该表面分块所属构件的工程重要度确定：

    ρ̂_i = ρ_0 · (1 + λ_E · E_i)

式中，ρ_0 为基准期望密度，E_i 为第 i 个表面分块所属构件的工程重要度且取值于 [0, 1]，
λ_E 为重要度系数。工程重要度较高的构件（如柱、梁、楼板）对应较高的期望密度。

表面分块的缺口分数的计算公式为：

    G_i = α · (1 − C_i) + β · max(0, 1 − ρ_i / ρ̂_i)

式中各符号含义同前，α 和 β 均为加权因子且 α + β = 1。本实施例中取 α = 0.60、
β = 0.40。

对于上述公式中的 max(0, 1 − ρ_i / ρ̂_i) 项：若 ρ_i ≥ ρ̂_i，则点云密度已达到期望
密度，该项取 0，此时该表面分块的缺口分数仅由几何覆盖率决定；若归属于该表面分块的
有效采样点数量为 0，则 ρ_i = 0，该项取 1。

> **【须核实】** 在采用"按构件面积比例分配采样点数量"的实施方式时，若几何覆盖率
> 亦由该分配所得的采样点数量导出，则 C_i 与 ρ_i 可能不再相互独立，此时 α 与 β 的
> 取值不再分别对应两个独立的量。若采用该实施方式，应在说明书中如实写明，或按前述
> 布置评估点的方式独立统计几何覆盖率。定稿前请与研发方确认后删除本提示框。

#### 关于步骤 S5：候选补扫视点的生成与价值计算

参见图 5，以目标表面分块的中心为原点、以其法向为第一坐标轴 e₁ 建立正交坐标系；第二
坐标轴 e₂ 取 e₁ 与竖直方向 z 的叉积并归一化，当 e₁ 与 z 近乎平行而该叉积退化时，改
取 e₁ 与 x 方向的叉积并归一化；第三坐标轴 e₃ 取 e₁ 与 e₂ 的叉积。

在该正交坐标系中，按预设的多个候选距离、多个方位角偏移与多个俯仰角偏移的组合生成
多个候选补扫视点。图 5 中三条同心弧线分别以实线、虚线和点线绘出，表示以目标表面分块
中心为圆心、以三个不同候选距离为半径所形成的三个候选距离层；空心圆表示所生成的候选
补扫视点，均位于其所属候选距离层的弧线之上；同一条弧线上的多个空心圆对应在该候选
距离层上分别叠加不同方位角偏移与俯仰角偏移所得的候选补扫视点。候选补扫视点的数量由
候选距离、方位角偏移与俯仰角偏移的组合数确定。自各空心圆引出的箭头表示对应候选补扫
视点的朝向，均指向目标表面分块中心。

参见图 6，编号 B1–B4 标识的矩形均为表面分块。对每一候选补扫视点，按下述三个条件同时
成立判定某一表面分块是否落入其视锥范围：该表面分块相对该候选补扫视点的正视度不小于
预设的正视度下限；该表面分块中心相对该候选补扫视点朝向的夹角余弦不小于视场角半角的
余弦；该候选补扫视点至该表面分块的距离不大于预设的最大量程。满足上述条件的表面分块
整体计入该候选补扫视点的价值计算，不满足者整体不计入。

候选补扫视点的价值的计算公式为：

    V_j = Σ_{k ∈ ℒ_j}  G_k · S_k · q_{jk}

式中，V_j 表示第 j 个候选补扫视点的价值；ℒ_j 表示第 j 个候选补扫视点的视锥范围所
覆盖的表面分块的集合；G_k、S_k 分别表示第 k 个表面分块的缺口分数与面积；q_{jk} 表示
第 j 个候选补扫视点对第 k 个表面分块的观测质量。

观测质量 q_{jk} 由下述三项之积确定：

    q_{jk} = f_{jk} · exp( −(d_{jk} − r_opt)² / (2σ²) ) · 1 / (1 + c · d_{jk})

式中，f_{jk} 为正视度，取第 k 个表面分块的法向与由该表面分块中心指向第 j 个候选补扫
视点的方向的点积并取其非负部分；d_{jk} 为第 j 个候选补扫视点至第 k 个表面分块的距离；
r_opt 为预设的最佳扫描距离；σ 为距离衰减尺度；c 为分辨率衰减系数。

本实施例中取正视度下限为 0.35、视场角为 90 度、最大量程为 20 米、最佳扫描距离
r_opt 为 2.5 米、分辨率衰减系数 c 为 0.15。距离衰减尺度 σ 可取固定值（本实施例取
2.0 米），亦可按最佳扫描距离缩放取 0.4·r_opt；需要说明的是，当候选距离层的取值远
大于最佳扫描距离时，若将 σ 一并按比例缩小，会使较远距离层的候选补扫视点的距离质量
急剧下降，因而在候选距离层跨度较大的场合宜取固定的 σ。

由上式可见，正视度使观测方向接近表面分块法向的候选补扫视点获得更高价值；距离质量
使扫描距离接近最佳扫描距离者获得更高价值；分辨率质量随距离单调递减。三项之积与缺口
分数、分块面积相乘后在视锥范围内求和，使所选视点倾向于覆盖缺口程度高、面积大且观测
几何较好的表面区域。

在一些实施方式中，步骤 S4 中亦可将缺口分数不小于预设缺口阈值的多个表面分块均作为
目标表面分块，分别按步骤 S51 生成候选补扫视点后合并为一个候选集合，再按上式计算各
候选补扫视点的价值并取价值最高者。
